## 开始使用

1. 正常退出并重新启动魔兽客户端。在角色选择界面的插件列表启用 **MyForever 个人宏工坊** 和 **我的无限 · 随身手册**。新装目录建议完整重启；只执行 `/reload` 不保证发现新插件。
2. 牧师角色输入 `/mypriest`：左侧选择牧师预设 → 已学技能自动填入 → 检查预览 → 点击“创建角色宏” → 点击“取到鼠标” → 放到动作条。输入 `/mymacro` 也可进入；牧师首次打开默认牧师页，左上角可切换通用模板。
3. 输入 `/myfield` 显示或隐藏随身手册。拖动标题可移动；`/myfield lock` 锁定或解锁；`/myfield reset` 从现在重新统计时间和金币变化。

已按你提供的**牧师**职业加入 11 个预设，兼顾治疗和单人练级；暂不假定等级、天赋或装备。具体操作见 [牧师使用说明](牧师使用说明.md)。四条无需职业技能的宏也可直接从 [宏模板](宏模板.md) 复制。

## 两个插件

| 插件 | 用途 | 命令 |
| --- | --- | --- |
| MyForeverMacros | 11 个牧师预设 + 11 种通用模板；按角色已学法术生成；骑士正义圣印缺失淡出提醒 | `/mypriest`、`/mymacro`、`/myseal` |
| MyForeverFieldKit | 区域坐标、普通背包空位、最低装备耐久、本次金币净变化与时长；保存面板位置、显隐、锁定状态 | `/myfield` |

法术选择器只列已学的普通主动玩家技能，合并同名技能等级。宠物技能、折叠技能如传送门等不在列表中，可手动填入与游戏语言一致的名称。不指定技能等级的宏仍由客户端处理等级选择。

宏工坊创建**角色宏**，不会自动修改动作条和按键。已有同名不同内容的宏会要求改名；已有同名同内容的角色宏可以直接拾取；所有创建均读取结果再次核验。修改既有宏请在游戏 `/macro` 中操作。宏预览可选中复制，创建接口受限时可手动新建。

随身手册的“普通背包空格”不包含专业袋、箭袋等专用空间；“耐久”是所有有耐久装备中的最低百分比，不是平均值。金币净变化包含购物、修理、交易等所有增减，不代表纯打怪收入。时间和金币统计在重新登录或 `/reload` 后重新开始；隐藏面板时保留统计起点。战斗期间暂停查询，脱战更新。坐标等数据暂不可用时显示 `—`。

## 使用宏前要知道

- 每次按键执行固定命令。多条有公共冷却的技能不会因此自动连续施放，也不会根据血量或冷却自动挑选技能。
- 条件从左向右匹配。焦点/鼠标目标存在但超出射程，或被遮挡时，不会因为施法失败再自动尝试下一个目标。
- 打断模板含 `/stopcasting`，会先取消自己的当前读条；光标落点模板省略二次确认；宠物召回会设置被动态度。这些行为也写在各模板提示中。
- Ctrl/Shift/Alt 组合键如已有其他绑定可能先被对应动作使用。鼠标侧键在部分单位框体上可能被点击绑定截获，先用普通键盘按键验证。
- 原生编辑框上限为 255 **字符**。本工具第一版采用更保守的 255 **UTF-8 字节**限制并明确显示，以避免未实测的存储截断；常见中文技能名均可容纳。创建后仍比对完整正文。
