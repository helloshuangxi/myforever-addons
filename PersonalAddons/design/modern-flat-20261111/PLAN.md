# 我的无限 · 静石：统一 UI/UX 美术圣经

日期：2026-11-11。目标：为当前七个自研插件建立现代、扁平且与魔兽世界语义兼容的视觉和交互规范。

## 约束

- 此轮为设计提案。只写独立设计目录；不修改游戏 AddOns、WTF、发行包或官网。
- 以当前源码的功能结构为基础；新增交互明确标为提案；原型使用虚构数据。
- 保留物品品质、职业、频道、配方难度颜色；不将品牌色覆盖游戏语义。
- 兼顾游戏 UI 逻辑像素、屏幕缩放、战斗受保护操作、窗口恢复、原生提示及既有功能。
- 七插件独立运行；原型左侧用于切换设计示例，不提议强制的游戏内总控制台。

## 文件与顺序

1. 只读检查七插件主界面和功能边界，形成信息与操作分级。
2. `ART_BIBLE.md` + `tokens.json`：设计原则、视觉数值、按钮/文字决策、七插件流程和验收规范。
3. `index.html` + `styles.css` + `app.js`：离线可运行的七插件交互预览及组件规范。
4. `book.html` + `MyForever-Art-Bible.pdf`：排版文档与可分享 PDF；`overview.png` 为总览。
5. 浏览器检查七个示例、键盘焦点、窄屏、失效状态、文档分页；检查 PDF 文本及渲染。

## 风险与验证

- 浏览器原型不等同游戏客户端：字体度量、Frame 锚点和 secure 行为留待后续本机开发实测。
- 精简操作不能改变按键、发消息或导航的实际权限；真实发送/创建/导出在原型只演示状态。
- 设计中的字号、尺寸、对比度需说明逻辑像素与浏览器展示缩放的区别。
- 对所有产物检查溢出、文字可读性和颜色含义，报告实际完成范围。
