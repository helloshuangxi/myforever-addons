# 我的无限 · 静石 v1.2

七个自研魔兽插件的统一美术与交互圣经。最高原则：尽量不要占用游戏主画面，让主画面干净。

所有插件外壳均为半透明底板，文字和图标保持不透明。默认不透明度：工具窗 84%、紧凑 HUD 72%、短时提醒 80%、浮层 90%。样张提供背景明暗和工具窗不透明度调节；材质示意不是游戏截图。

以 Apple 的清晰层次、精简工具、上下文与小型 HUD 为参考，采用游戏内原生工具窗的呈现方式。样张中没有网站导航侧栏或介绍区；上方控制条仅供切换设计示例，不会进入游戏。

## 从哪里看

- `MyForever-Art-Bible.pdf`：19 页图文手册，包含净空原则、四种显示状态、配色尺寸、信息层次、按钮/文字决策、七插件样张及验收。
- `index.html`：直接用浏览器打开，可离线切换七插件、收起/展开/提醒/战斗/空态/不可用、密度和外观浮层。
- `book.html`：完整正文阅读版。
- `ART_BIBLE.md`：可维护的规范源文件。
- `tokens.json`：可供后续 Lua 外观映射的视觉数据，不是插件运行库。
- `overview.png`：手册封面。
- `VALIDATION.md`：设计与原型验证范围。

## 交付边界

这是设计提案，未改游戏 AddOns、WTF、下载 ZIP、版本或官网。所有人物、消息和状态均为示例；目录中有可识别 NPC 的记录时也不能据此判断当前角色位置与实时距离。示意图中的简化功能图标不是最终游戏素材，实际游戏对象继续使用客户端原生图标。

原型的发送、创建宏、导航、焦点、标记和导出只展示界面反馈，不连接游戏。采集提示音、闪光及旧用户配置没有被修改。后续实现需要按每个插件的权限与客户端限制单独验收。

字体在浏览器中采用本机字体回退；PDF 嵌入本机可用于文档嵌入的中文字体。插件交付不会附带 Apple SF 字体、SF Symbols 或其他新增字库。

## 维护

正文与 tokens 由设计决定维护；更新后运行 `python3 build_pdf.py` 可重建 PDF 与阅读版，需要本机 ReportLab、pypdf 和脚本指定的中文字体。PDF 图文模板应随正文一起复核。`qa/` 与 `tmp/pdf/` 为当前验证证据。
