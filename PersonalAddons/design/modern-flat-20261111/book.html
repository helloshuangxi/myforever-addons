# 我的无限 · 静石

## 自研插件统一美术与交互圣经 · 设计提案 1.2

2026-11-11｜适用：聊天、商业技能助手、世界向导、目标选择、个人宏工坊、随身手册、AI 教练。

**本文件规定后续改版的目标，不代表这些界面已经在游戏内实现或验收。** 配套预览中的人物、数值与会话均为虚构示例；本次仅交付设计资料，不修改运行中插件、不生成发行 ZIP、不更新官网。

## 原则 1：主画面优先，插件按需出现

**尽量不要占用游戏主画面，让主画面干净。** 所有配色、排版与操作便利都服从这一原则；“所有功能看得见”不等于“所有窗口同时常驻”。

以下是新安装与后续改版的默认建议，不代表已修改当前插件；用户已有的显示选择、窗口位置、尺寸与提醒设置继续保留，不强制覆盖。

| 显示状态 | 允许出现什么 | 出现与退出规则 |
|---|---|---|
| 游戏默认态 | 当下需要的紧凑信息，其他主窗隐藏或收起 | 登录不把七个工具窗全部打开；已有用户选择优先 |
| 主动展开态 | 玩家正在使用的完整工具窗与对应详情 | 主动打开后保持操作上下文；用后可关闭，关闭不冒充暂停业务 |
| 短时提醒态 | 一条明确的新事件或必要状态 | 同类合并，同屏最多一条通知；建议展示 2–3 秒，重要未解决状态另在相关对象旁保留 |
| 战斗态 | 目标、危险与当前任务必需的信息 | 不主动弹大窗、不抢输入焦点；受保护框体沿用原有安全机制，不动态改 secure 属性或随意增删显示 |

| 插件 | 建议游戏默认态 | 何时展开或短时出现 |
|---|---|---|
| 聊天 | 完整聊天窗按需打开 | 必要私聊可短时单行提示，默认不展示正文；频道每条消息不逐条弹窗 |
| 商业技能助手 | 隐藏或收起 | 主动看进度时展开；仅真实新发现短时显示资源名称，保持已有声音与闪光设置 |
| 世界向导 | 无激活导航时隐藏 HUD | 激活导航后显示 300 × 84 紧凑 HUD；查找目的地时才打开完整窗 |
| 目标选择 | 只显示玩家需要的友方/敌方分组 | 沿原有安全机制显示需要的单位；不能为净空在战斗中临时改受保护布局与显示逻辑 |
| 个人宏工坊 | 隐藏 | 玩家主动打开编辑，完成后关闭；圣印等必要提醒仍按已有设置独立工作 |
| 随身手册 | 默认隐藏；紧凑单行由玩家按需启用 | 主动查看时展开，不额外常驻多张状态卡 |
| AI 教练 | 隐藏 | 主动检查或导出时打开，用后关闭；关闭不自动等于停止本地采集 |

净空布局参考：屏幕中间 **40% 宽 × 55% 高** 尽量不放常驻插件框体，保护人物、脚下机制与战斗观察。这是可调整的设计参考，不是自动挪动现有 UI 的规则。原生小地图、任务追踪、目标框、动作条与读条同样需要避让；边缘也不能无限堆积。

不新增常驻七插件导航侧栏、底部启动坞或成排小地图入口。配套预览的插件切换导航仅属于设计浏览器，不能直接照搬进游戏。七个主窗不同时主动弹出；玩家自己打开多个窗口时保留其选择，不自动关闭正在编辑的内容。

净空不等于隐藏关键风险：当前目标、焦点、失败原因、必须处理的状态仍需清楚；优先缩减背景说明和低频工具入口。通知消失不能清除未完成任务，也不能让玩家误以为错误已经恢复。

## 原则 2：原生工具感，不做网页后台

学习 Apple 的简洁、层次、上下文保持、可预期的一致性，以及小而不打扰的 HUD；形成适合魔兽的原生工具界面。这是 Apple 思路的适配提案，不是苹果原生组件或官方界面。

- 小标题栏说明当前工具，精简工具栏只放当下常用动作；同级模式用分段控件，选中态清楚稳定。
- 列表整行选择；对象详情就近展开为检查面板（Inspector）或轻量浮层（Popover），关闭后回到原对象与滚动位置。
- 七个插件各有合适的结构：专业与手册是小工具窗，聊天是对话窗，导航是 HUD，目标是单位格，宏是编辑器，教练是检测表。
- 不做网页介绍 Hero、常驻全家桶侧栏、功能卡片阵列、大 KPI、欢迎页或跨插件仪表盘；样张工具条也不属于游戏界面。
- 不照搬 macOS 交通灯按钮，不使用 iOS 式巨大触控控件，不引入强玻璃。WoW 不假设支持实时背景模糊，默认使用可读的石墨半透明表面。
- 同一任务的名称、位置与反馈保持一致；同一家族不等于每个插件必须使用相同宽度、相同分栏与相同按钮数量。

## 设计命题

让玩家更快看懂下一步，同时让艾泽拉斯继续占据屏幕中心。

- 现代化来自准确的信息层次、规整对齐、原生工具结构和及时反馈。
- 游戏气质来自原生技能与物品图标、熟悉的语义色，以及克制的石墨与金属色调。
- 默认安静：不靠大面积亮色、玻璃、发光、厚重浮雕或持续动画争抢注意力。
- 操作就近：需要行动的信息旁边就有入口，读一个数字不必打开一页设置。
- 同一家族、独立使用：七个插件共享视觉语言，不强制同时安装，也不强制塞入一个总面板。

## 与魔兽世界的边界

| 保留 | 统一 | 禁止混淆 |
|---|---|---|
| 原生技能、物品、职业与团队标记图标 | 窗口底色、间距、排版和交互反馈 | 选中色不替代物品品质、职业、敌友和难度色 |
| 物品链接及其原生提示语义 | 本插件按钮、输入框、列表和设置 | 不把全部资源、任务与玩家做成同色图标 |
| 游戏已有的按键和目标操作习惯 | 本插件内图标尺寸、裁切与留白 | 不覆盖角色移动、镜头转向或其他插件的设置 |
| 各插件已实现的能力与限制 | 说明文案、失效状态和恢复入口 | 不用视觉改版暗示导航、自动施法或 AI 已新增 |

外观改版只处理本插件拥有的框体。原生地图、技能书、游戏菜单与其他插件不做全局换肤。

## 视觉基底

### 颜色角色

| 角色 | 色值 | 用途 |
|---|---|---|
| 场景衬底 | `#111214` | 设计画布；游戏内不额外铺满屏幕 |
| 主面板 | `#222326` | 工具窗口、按需信息条 |
| 抬升表面 | `#303236` | 输入框、选项、局部详情 |
| 悬停表面 | `#3A3D42` | 可交互区域悬停与中性选中背景 |
| 分隔线 | `#4B4F56` | 必要边界；避免每行、每块都画框 |
| 主文字 | `#F5F5F7` | 名称、正文、当前结果 |
| 次文字 | `#C0C3C9` | 单位、来源、简短说明 |
| 辅助文字 | `#969BA5` | 时间、版本、非关键提示；不用于警告 |
| 选中与链接 | `#8BBEF3` | 选中指示、键盘焦点、本插件普通链接 |
| 浅蓝强调上的深字 | `#132335` | 确需使用浅蓝实底标记时的文字 |
| 主按钮填充 / 文字 | `#0A64C5` / `#FFFFFF` | 明确执行动作；不透明色样对比度约 5.77:1 |
| 成功 | `#79D7BE` | 已完成结果与成功状态，不再用作全局主按钮色 |
| 专业金 | `#E2C183` | 专业与地点的少量重点；不表示物品品质 |
| 注意 | `#F2C46D` | 材料不足、待脱战、需要检查 |
| 错误 | `#F28B82` | 操作失败、接口拦截、失效目标 |
| 信息 | `#8DBFF2` | 仅见事件、普通提示、参考信息 |

颜色必须承担含义。状态总带文字或形状：`已暂停`、`材料不足`、选中勾、焦点框，不能只靠变色。

### 形体、材质与图标

- 面板圆角 6，按钮与输入框 4，列表行与图标裁切 2；全部为逻辑像素，不做大圆角卡片。
- 使用纯色半透明填充。默认不加渐变、投影、纹理噪点、发光边和全屏磨砂。
- 七个插件的所有面板都使用下方所属角色的透明度；文字与游戏对象保持清楚，不随背景一起变淡。
- 游戏对象使用客户端原生图标；功能操作使用同一组简洁线性图标，24 像素画布、约 1.5 像素笔画。
- 原生图标不重新生成，不改色；仅统一尺寸、裁切和边距。罕见品质保留原色与完整名称。
- 关闭、锁定、设置、收起四种全局动作的位置和图标固定；危险动作不藏在无标签图标里。

### 透明度与清晰度

本规范的 **alpha 表示不透明度**：alpha 0.84 = 不透明度 84% = 透明度 16%。控件和说明同时标注不透明与透明百分比，避免把数值方向调反；下列均为设计建议，未改游戏内设置。

| 背景角色 | 默认不透明度 alpha | 对应透明度 | 用户可调不透明度范围 |
|---|---:|---:|---:|
| 主工具窗 | 0.84（84%） | 16% | 0.72–0.94（透明 28%–6%） |
| 导航 / 随身紧凑 HUD | 0.72（72%） | 28% | 0.60–0.90（透明 40%–10%） |
| 短时提醒 | 0.80（80%） | 20% | 0.70–0.92（透明 30%–8%） |
| 外观 / 上下文浮层 | 0.90（90%） | 10% | 0.82–0.96（透明 18%–4%） |

| 插件 | 面板透明角色 |
|---|---|
| 聊天 | 对话主窗 0.84；必要消息短提示 0.80；外观与上下文浮层 0.90 |
| 商业技能助手 | 专业主窗 0.84；新资源名称提醒 0.80；设置与详情浮层 0.90 |
| 世界向导 | 查找主窗 0.84；激活导航 HUD 0.72；上下文浮层 0.90 |
| 目标选择 | 所需友方 / 敌方分组面板 0.84；标记与上下文浮层 0.90；目标 / 焦点标识不透明 |
| 个人宏工坊 | 编辑主窗 0.84；圣印等短时提醒 0.80；技能选择 / 上下文浮层 0.90 |
| 随身手册 | 展开主窗 0.84；按需紧凑单行 HUD 0.72；上下文浮层 0.90 |
| AI 教练 | 检测与导出主窗 0.84；外观 / 上下文浮层 0.90 |

仅背景 Texture 使用 RGBA 填充；不能用父 Frame 的全局 `SetAlpha` 实现主题透明，以免子文字一起变淡。文字、图标、物品链接、生命条及当前目标 / 焦点标识维持 alpha 1；普通边框约 0.55，重要目标与焦点边框仍保持清楚。

子背景只做轻量分区，避免多层背景叠成实心卡片。亮色或复杂场景优先增加局部文字背板，或由用户把背景不透明度调至所属范围上限，仍保留一定透明；不承诺识别背景、自动调参、全透明或实时模糊。

不透明色样的静态对比度不能代表与所有游戏场景合成后的可读性。透明面板须分别叠在深色、浅色与复杂场景检查，尤其复核主文字、链接、生命条、当前目标和焦点；既有显示、声音与闪光等用户选择保持原状。

## 字体、尺寸与密度

| 层级 | 建议逻辑字号 | 字重与用途 |
|---|---:|---|
| 窗口标题 | 16 | 清晰常规或中等字重；不使用描边装饰字体 |
| 关键结果 | 18–20 | 仅当前距离、重要数值或短警告；一窗通常一处 |
| 主内容 | 13 | 名称、正文、按钮文字 |
| 次说明 | 12 | 来源、单位、辅助条件 |
| 紧凑辅助 | 最低 11 | 时间、索引；不放核心操作与关键状态 |

优先使用客户端已经提供的中文字体，正常字重、无描边；不得为换肤引入来源不明或未获授权的字体。数字使用等宽数字能力时需确认客户端字体支持，不能假设支持。

SF 字体与 SF Symbols 不随插件打包；预览不代表取得其再分发授权。最终仅使用客户端已有的授权字体、原生图标及另行确认可用的功能图标。

基础间距 4；常用间距为 4、8、12、16、24。文字基线对齐，数字列右对齐，物品名称左对齐；单位紧跟数字，不靠距离猜单位。

| 控件 | 建议尺寸 |
|---|---|
| 标题栏 / 工具栏 | 高 36 / 32 |
| 普通列表行 / 双行详情 | 高 34 / 最小 44，长文字可增高 |
| 输入框 | 高 30 |
| 普通 / 主要按钮 | 高 28 / 32 |
| 图标按钮 | 命中区至少 28 × 28；图形不必填满 |
| 目标方格 | 延续 56 × 56 基准，不因统一风格强制变成大列表 |
| 面板内边距 | 通常 12；密集目标网格 4–8 |

所有数值是设计起点，不覆盖已验收的缩放、拉伸和最小尺寸。以客户端 UI 缩放、实际分辨率和中文长文本验收；预览里的 CSS 像素不等于最终游戏物理像素。

## 信息哪些突出

| 优先级 | 内容 | 显示方式 | 示例 |
|---|---|---|---|
| 第一眼：当前决策 | 当前对象、必须应对的状态、下一步 | 主文字；一处重点或短状态条 | 当前目标、材料不足、当前导航目的地 |
| 第二眼：行动依据 | 进度、数量、范围、可用性 | 正常正文、进度条、小型状态标记 | 42 / 75、还缺 2 个、直线约 180 米 |
| 第三眼：背景说明 | 来源、采样时间、限制、版本 | 次文字或就近提示；必要时展开 | 上次记录、待观察、版本号 |
| 按需：诊断与维护 | 完整日志、长规则、详细配置 | 详情区或设置页 | 导出 JSON、能力诊断、外观参数 |

同一窗口最多一个最高视觉权重。标题不能比实际错误更亮，版本不能比材料短缺更抢眼，所有按钮不能同时高亮。

重要限制与结果一起出现：`直线约 180 米`、`上次记录 · 打开专业可更新`、`尚未连接 AI`。它们不能只藏在帮助页，也不能用大段免责声明占据主区。

## 哪些是按钮，哪些是文字

| 类型 | 判定 | 视觉与文案 | 例子 |
|---|---|---|---|
| 主要按钮 | 会执行当前窗口最重要的明确动作 | 深蓝填充白字、动词开头；同一局部最多一个 | `发送`、`开始导航`、`创建角色宏` |
| 次要按钮 | 常用且有独立结果 | 中性底，悬停变亮 | `查看地图`、`从法术本选`、`暂停采集` |
| 文字按钮 | 次要、可逆、上下文明确的动作 | 仍有完整命中区与悬停态 | `展开材料`、`查看详情`、`恢复默认` |
| 选择行 | 选择对象后在旁边查看或操作 | 整行可点，选中背景与勾/边框 | 配方、会话、NPC、宏模板 |
| 交互文字 | 游戏对象已有原生点击语义 | 保留原生链接色、提示与鼠标反馈 | 物品链接、训练师位置入口 |
| 纯文字 | 不产生动作的事实、单位或状态 | 无按钮底、无假悬停、不画下划线 | `耐久 86%`、`采集已暂停`、`上次记录` |
| 开关 | 一个持续生效的二选一设置 | 文字标签 + 开关 + 当前状态 | `采集提示音`、`窗口锁定` |

`材料不足`不是按钮；旁边需要查看材料时才放`展开材料`。`已暂停`不是按钮；继续工作才放`继续采集`。`123 米`不是导航按钮；目的地行选择与`开始导航`分开。

不为每一条数据制作胶囊标签。徽标只表示精简状态，普通分类用文字。图标按钮须有悬停名称；高频动作不能只靠用户记忆图案。

## 统一窗口与操作架构

- 标题栏：左侧插件名称，右侧固定的锁定、收起或关闭；只显示该插件实际支持的动作。
- 工具栏：只放当前任务必要的分类、搜索和一项常用操作，不堆放全部设置。
- 主区：列表与详情保持稳定位置；短小插件保留单栏，不为了统一而增加侧栏。
- 底部：仅放操作结果、必要条件或简短帮助；版本与开发日志进入关于或诊断。
- 弹窗：只用于必须立即处理的冲突或确认；普通成功反馈用就近文字，自动淡出后不改变布局。
- 设计预览的“七插件导航”是浏览设计用的，不代表游戏中增加常驻总启动器。

主操作尽量一至两次点击完成。连续任务保留当前分类、搜索词与滚动位置；关闭后重开回到原位置，除非对象已经失效。

## 控件状态与反馈

| 控件状态 | 必须看见 | 操作规则 |
|---|---|---|
| 默认 | 可读标签与清楚命中区 | 装饰不伪装成可点区域 |
| 悬停 | 底色提高一个层级；必要时提示 | 不移动文字、不改变行高 |
| 按下 | 表面降低或选中标记 | 点击瞬间反馈，不播放夸张弹跳 |
| 选中 | 稳定底色 + 勾/边框/文字状态 | 悬停不能抹掉当前选中对象 |
| 键盘焦点 | 清晰浅蓝焦点框 | 与鼠标悬停、当前选中分别表达 |
| 禁用 | 文字仍可读，状态理由就近显示 | 不仅降低透明度；说明何时可用 |
| 读取中 | 短文字 `正在读取…` | 保留已有布局，不闪白、不伪造进度 |
| 成功 | 就近结果，如 `已创建角色宏` | 显示真实完成结果后再提供下一步 |
| 失败 | 原因 + 可执行的修正入口 | 保留输入与选中对象，不反复弹同一错误 |
| 无数据 | `尚无记录`或准确原因 | 未知用 `—`，已知为零写 `0` |

短反馈建议 100–160 毫秒；关闭可更快。减少动态效果时直接切换状态。列表刷新不每次整体闪动，频繁变化的数字不跳动宽度。

## 七个插件的具体规范

### 聊天 · 先看谁在说什么

当前结构有会话、联系人、群聊入口，以及聊天记录、输入与外观设置；频道与发送能力必须以现有代码和客户端限制为准。

- 最突出：当前会话名称、未读消息、消息正文；发送对象始终可见。
- 次突出：发送者、频道/群归属、物品链接；时间和历史来源降低一级。
- 纯文字：在线状态、时间、系统说明；按钮：`发送`、添加/管理入口与必要的聊天操作。
- 会话整行可选，未读有数量或标记；输入区常驻，主要发送动作贴近输入框。
- 私聊、小队、团队、公会等保留既有频道语义色；本人气泡使用安静的中性/低饱和底，不能吞掉物品品质色。
- 最短流程：选会话 → 输入 → Enter 发送；发送失败保留草稿，错误就近显示，不把失败文本清空。
- 历史记录、模拟预览与实时消息必须有准确区别；不能把历史内容当成新消息触发提醒。

### 商业技能助手 · 先知道现在练什么

当前具备专业进度、推荐训练、材料、训练师与采集提醒等能力；本机候选的实验状态仍适用 AGENTS.md。

- 最突出：当前专业、等级进度、推荐项目；材料不足紧邻项目，不放在窗口最末尾。
- 次突出：难度及是否为上次记录、材料已有/需要数量、训练师入口。
- 专业标题行可展开；配方是选择行，材料是带数量的文字/原生物品链接，不能做成“点击购买”假动作。
- 按钮：已验收的顶部技能书入口保留；训练师/地图动作保留明确名称和点击反馈。
- 配方橙黄绿灰难度色延续游戏语义，同时写出难度名称；进度不得暗示每次操作保证升级。
- 最短流程：展开专业 → 选择推荐 → 看缺料；打开技能书与训练师入口不藏入设置。
- 采集提醒只突出新确认的资源名称；无方位、距离、箭头或“附近路线”。保持既有声音、闪光和提醒设置。
- 可拉伸窗口、缩放、收起与顶部技能书的已验收能力不得回退；旧悬停/缓存不冒充新发现。

### 世界向导 · 先确定要去哪

当前有找 NPC、我的地点、当前导航，并有紧凑方向 HUD；导航距离与方向为直线参考。

- 最突出：选中目的地、位置类别、当前导航目标；HUD 只保留目的地、方向与必要距离。
- 次突出：地图/区域、NPC 身份、坐标、数据来源；不可用条件与目的地并列。
- 搜索与分类用于缩小列表；NPC/地点整行选择，右侧详情只放当前对象。
- 按钮：`开始导航`、`查看地图`、停止当前导航；地点名称与坐标本身不伪装成按钮。
- 当前导航状态与停止入口相邻；不重复显示多个竞争方向箭头。紧凑 HUD 延续 300 × 84 基准；方向无效时隐藏箭头并写明原因。
- 最短流程：搜索或分类 → 选目的地 → 开始导航；既有任务导航入口与双击行为继续可用。
- 明写 `直线参考`，不绘制未实现的道路路径、不承诺绕障、ETA 或自动行走。

### 目标选择 · 先辨认单位，再执行动作

当前分友方与敌方，有团队、小队、附近等模式；左键目标、右键焦点、Ctrl+右键标记等需保留现有受保护交互语义。

- 最突出：单位名称、生命、当前目标与失效状态；延续红框表示当前目标、黄框表示焦点，可叠加，并补充`当前`/`焦点`文字。
- 次突出：职业、任务标记、可用范围信息；未知距离不编造精确米数。
- 单位格就是操作控件，不再给每格附三个按钮；说明通过底部短提示与悬停展开。
- 职业色仅作名称/小条，生命危险色与敌友语义不得由品牌色替代；死亡、离线与过期单位有文字标志。
- 分类和位置锁定留在标题附近；诊断、实验开关移出战斗主区，不能挤占单位面积。
- 最短流程：看到单位 → 按既有点击手势操作；改变布局、模式和受保护设置先脱战。
- 外观统一不改变 secure attributes、宏内容、单位绑定或战斗行为；每类输入都须真实客户端复验。

### 个人宏工坊 · 先看生成内容，再创建

当前从模板和本角色已学技能生成可复制预览，创建角色宏后可取到鼠标；有通用与牧师分类及圣印提醒。

- 最突出：所选模板、有效技能与最终宏预览；创建失败原因靠近主按钮。
- 次突出：适用目标规则、字节限制与可用条件；不把完整帮助塞到模板列表中。
- 模板为选择行；技能字段有常驻标签与`从法术本选`次按钮；宏名称为输入框。
- `创建角色宏`是主按钮；成功后`取到鼠标`成为清楚的下一步，不在创建前假装可用。
- 宏预览使用代码排版、可全选复制；创建结果始终与可见预览一致，不能偷偷执行编辑后未展示内容。
- 最短流程：选模板 → 选技能 → 检查预览 → 创建；不重新分配用户动作条按键。
- 战斗中标明哪些操作需脱战；圣印提醒沿用当前设置，不借换肤改变触发规则。

### 随身手册 · 一眼扫完旅途状态

当前提供区域坐标、普通背包空格、装备耐久、本次净收支与旅途时长；战斗中暂停数据更新。

- 最突出：当前区域与需要处理的背包/耐久状态；正常时保持均衡，不把每个数字都放大。
- 次突出：坐标、净收支、旅途时间；金额明确正负与单位，未知显示 `—`。
- 大多数内容是纯文字，不增加六张卡或六个按钮；锁定、关闭保留轻量入口。
- 重置旅途归入次级操作并说明影响；设计若增加按钮，必须标注为新交互提案并单独实现验收。
- 最短流程：打开即读；常驻后无需操作。拖动仅从标题栏开始，锁定后不因误拖改变位置。
- 战斗暂停时明确 `战斗中 · 数据暂停`，不把上次耐久/坐标包装成实时值，统计起点保持原有行为。

### AI 教练 · 先知道采集是否有效

当前是本机能力检测与有限会话采集原型，尚未连接 AI，不提供自动施法、按键控制或路线推荐。

- 最突出：`尚未连接 AI`、采集状态、接口拦截/暂停原因；这不是装饰性脚注。
- 次突出：本会话记录数、丢弃数、当前场景；能力矩阵按项目与脱战/战斗/副本/PvP 对齐。
- `已读到`、`部分受限`、`受限`、`仅见事件`、`无数据`、`待观察`逐字保留区别；不能全部缩成绿勾红叉。
- 按钮：暂停/继续采集、重新检测、新会话、导出 JSON、诊断摘要；隐藏面板与暂停采集不能使用同一图标。
- 最短流程：打开 → 读采集状态 → 按需暂停或导出；查看诊断不要求先停止有效采集。
- 导出仍遵守现有脱战限制和本机展示范围；按钮不得暗示已经上传、AI 已分析或功能已验证。

## 声音、提醒与屏幕占用

- 声音只服务需要注意的新事件，不为标签切换、开关与普通刷新新增播报。
- 同源重复事件合并，不堆叠声音与弹窗；具体去重时长是实现参数，须实测确定，不能用 UI 提案偷偷改触发逻辑。
- 提醒位置可预览；保留名称、必要图标与关闭入口，避免遮住角色脚下、读条、目标与原生小地图。
- 不主动放大全屏、不因弹窗抢走键盘输入；关闭窗口不等于停止业务行为，二者要分别命名。
- 对采集实验保留输入/地图恢复边界：点击、转镜头、战斗、离世、地图变化与错误优先恢复原地图及本插件拥有的输入状态。

## 鼠标、键盘与失效恢复

标题可拖动、控件不触发拖动；拉伸把手不覆盖关闭和主操作。大按钮与链接共处时命中区不互相重叠。

输入框不默认抢焦点；Tab 顺序遵循阅读顺序。Escape 先关闭菜单/清除输入焦点，再按插件既有关闭约定处理窗口，不新绑定全局按键。

目标或数据失效后保留上下文与错误原因，停止误操作入口；只有在重新核验后恢复可用，不把旧 GUID、缓存或历史状态套给新对象。

## 实施顺序与验收门槛

先做共用颜色、字体与控件样式，再逐插件替换外观；每个插件保留独立加载与卸载能力。不要用一个共享插件成为全部界面的强制依赖。

每次迁移先记录原尺寸、位置、设置与行为基线；外观变化与功能新增分开验收。保留原设置所有权，不以统一主题重置个人配置。

- [ ] 所有示意图标明提案；虚构人物和样例数据不会进入实际聊天、日志或官网截图。
- [ ] 第一眼能指出当前对象、状态和下一步；纯文字、选择行和按钮无需试错即可区别。
- [ ] 默认态、主动展开态、短时提醒态、战斗态分别截图；无任务时主画面保留净空，未增加常驻总导航或入口堆积。
- [ ] 样张仅保留工具结构，没有网页 Hero、全家桶侧栏、卡片阵列或大 KPI；检查面板/浮层关闭后保留上下文。
- [ ] 登录、切地图与收到消息不会同时弹多个主窗；关闭重开保留用户选择，不抢聊天输入或角色操作焦点。
- [ ] 同屏最多一条通知、同类合并；2–3 秒是可验证的建议时长，关键未解决状态仍有稳定可见入口。
- [ ] 原生小地图、任务追踪、目标框、动作条、读条与中央净空参考区均检查遮挡；按用户布局调整，不自动搬动其窗口。
- [ ] 目标分组与战斗显示沿原机制验证；净空策略不动态改 secure 属性，不隐藏当下必须处理的信息。
- [ ] 主文字及按钮文字按至少 4.5:1 的内部对比度目标检查；关键状态不只依赖颜色。
- [ ] 七插件每个面板按角色使用半透明背景；不透明度 alpha 与透明百分比同时标明，默认及可调上下限无反向混淆。
- [ ] 在深色、浅色、复杂场景分别验证默认与范围端点；静态色样对比不替代合成画面检查，必要时局部背板或用户调高不透明度。
- [ ] 仅背景纹理带透明度，文字、图标、链接、生命条和目标 / 焦点标识保持 alpha 1；无父 Frame 全局变淡或层层叠成实心卡片。
- [ ] 1080p 与高分屏、常用 UI 缩放下读得清；长中文、长物品名与缺失数据不遮挡操作。
- [ ] 最小/最大窗口、拉伸、收起、滚动、锁定、关闭重开与多插件并存都验证；商业技能助手既有验收不回退。
- [ ] 悬停、选中、焦点、禁用、读取、空态、错误与战斗限制都有可辨反馈。
- [ ] 普通点击、右键、修饰键、聊天链接、技能书和地图入口逐一真机复验；模拟通过不能写成游戏实测。
- [ ] 战斗、离世、切地图、对象失效和错误后无残留输入拦截；不修改其他插件框体或设置。
- [ ] 提醒、声音与闪光沿用已有设置；旧缓存/历史内容不误报为新事件。
- [ ] 设计交付不是上线授权；商业技能助手候选继续暂停公开发布。其余插件正式更新仍按 AGENTS.md 的版本、包和官网同步流程执行。

## 本提案的源码依据

范围与当前版本来自七个插件的 `.toc`；界面与交互依据各插件现有 `UI.lua`、`Main.lua` 及 README。核心参考是 `MyForeverProfessions/UI.lua` 的拉伸/技能书/推荐详情，`MyForeverTargets/UI.lua` 的单位安全点击，`MyForeverCoach/UI.lua` 的能力矩阵与导出限制，`MyForeverMacros/Main.lua` 的预览创建流程，以及 `MyForeverFieldKit/Main.lua` 的暂停与锁定行为。

这里的尺寸、统一组件与简化布局均为设计目标；正式实现必须重新核对当时源码与客户端能力。配套 `tokens.json` 是可供开发映射的设计数据，不是可直接加载的 WoW 运行库。
