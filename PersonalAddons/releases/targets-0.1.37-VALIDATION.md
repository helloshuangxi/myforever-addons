# 目标选择 0.1.37 试用版验证范围

发布日期：2026-11-11。兼容环境：国服《魔兽世界：无限》1.60.1 build 70862，Interface 16001。游戏实测在 Apple 芯片 Mac 上完成，尚未在 Windows 游戏客户端独立验证。

## 已验证

- 21个Lua文件语法与6990项模拟检查通过；涵盖独立开关、战斗待应用设置、身份保护、相关效果筛选、位置保存、图标菜单及安装依赖。模拟不等同游戏安全执行环境。
- 游戏内已验证附近玩家左键选择、右键焦点与焦点黄框；重复点击保留目标／焦点。
- 用户已验证脱战悬停附近友方，按普通治疗／增益键施放成功，随后恢复原目标。
- 用户已验证面板实际拖动后不回弹，重载后位置保持。
- 游戏内已验证紧凑血量／资源条界面、自身有时限增益保留、常驻光环隐藏；统一“目”字图标在左侧正常显示，重载后保留已保存位置和面板关闭状态。

## 限制与待验证

- 普通技能兼容仅在脱战时准备动作，会短暂选择单位并恢复原目标；会改变lasttarget历史。进入战斗后交还原技能键，不能保证战斗中的悬停施法。
- 敌方及敌人的目标条普通技能尚未验证成功；敌方方块的原生 `@mouseover` 已有失败记录，不作为已实现能力宣传。已有玩家宏保持原内容和按键。
- 名称兼容不能仅凭GUID精确区分同名怪物；发现同名或身份不明确时拒绝准备名称动作。
- 距离是可用接口估计的区间；未知距离排后，不承诺发现所有屏幕外或超出姓名板可见范围的单位。
- 可驱散减益、敌人目标条的数据填充、大量效果滚动、战斗中的原生光环限制与新开关交互仍需更多游戏场景验证。
- 独立关闭按钮、图标菜单／拖动和战斗排队已有模拟检查；本次发布不将这些模拟扩大为全部硬件鼠标或战斗场景实测。

诊断默认关闭，可用 `/mytargets log start` 手动开始。诊断只保存在本机，可能包含目标名称、GUID和技能事件；不随发行包提供，不记录聊天或宏正文。游戏通常在退出或 `/reload` 时写盘。

安装包仅包含插件代码、第三方库与许可、使用说明及本验证范围；不包含账号目录、WTF、SavedVariables、个人配置或日志。
