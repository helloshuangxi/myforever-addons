# MyForeverTargets 0.1.46 公开验证范围

发布日期：2026-11-12；状态：试用版。适配国服《魔兽世界：无限》1.60.1、Interface 16001；本机验证环境为 macOS。其他平台、客户端版本及所有界面比例未逐项实机验收。

## 发布内容

本包冻结自已验证的 0.1.44 功能基线。与该基线相比，仅 Core.lua／TOC 升版本和公开 README 更新，运行功能代码相同；增加此公开验证文件。排除 0.1.45 的 NativeScaleProbe 及 Main/UI 实验接入。其他原有诊断模块及默认策略保持基线，不以研究结果宣称修复战斗焦点。

## 已有游戏验证

- 用户确认：脱战悬停另一位玩家格子，按原普通治疗／增益技能可对悬停者施放，并恢复原目标。通过临时选中兼容完成，不能据此证明所有格子具备原生 mouseover。
- 0.1.43 合并流程：非空原目标 A、同名怪焦点 B 的六轮记录中五轮完整成功，一轮恢复未完成后中止。五轮成功均两次右键，最终焦点和原目标 GUID 及延迟读回一致；中止记录不计成功。
- 0.1.42 分步流程：四轮同名怪正确设焦点，并将原本为空的目标恢复为空。该结果不等同于默认合并模式空原目标通过。
- 0.1.44 普通游戏：用户确认友方面板位置正常。本机 1920×1080、两侧各 5 格时的七次几何快照均在屏幕内，且未与六组当时可见的原生动作条相交。手动拖动后位置保留。几何记录不代表覆盖所有第三方动作条或视觉效果。
- 0.1.44 两次脱战名称兼容焦点成功并恢复空目标，三次保留已有焦点。七次战斗内姓名板焦点尝试仍被脱战限制拒绝，未作为修复。

## 本版静态及模拟验证

隔离发布源通过 23 个 Lua 5.1 文件语法检查及 19 套、9820 项模拟检查。测试副本排除未进入发布源的 NativeScaleProbe 套件，并仅移除 UI 中对应的探针停用用例；其余用例完整执行。覆盖普通技能桥、焦点流程、目标条、光环、布局、开关及状态恢复等。模拟只验证 Lua 行为、接口边界和状态恢复，不执行真实客户端安全动作。

## 已知限制及待实测

- 脱战普通技能桥不是通用原生 mouseover；不改写玩家宏、永久键位，进入战斗会归还原技能键。
- 战斗中任意附近敌人及同名怪 GUID 自动匹配焦点未解决，不能宣传为战斗焦点修复。
- 敌方及敌人的目标条普通技能兼容尚未完整实测成功，敌方方块原生 `@mouseover` 仍有限制；同名怪的名称施法不唯一时拒绝。
- 默认合并模式的空原目标、完整多步恢复、友方别名恢复和战斗中断等边界仍待各自游戏验收。多次右键流程会改变上一目标历史，未完成不能仅凭焦点成功视为完成。
- 可显示单位及距离排序受姓名板可见范围、游戏接口、战斗限制和数据可读性影响。效果滚动、焦点头顶标记等不扩大为所有场景的验收承诺。
