# 无限服宏与个人插件兼容性研究

日期：2026-11-05（中国标准时间）。结论面向本机安装，不代表所有旧版插件均可运行。

## 本地事实

- 游戏根目录 `.build.info`：产品 `wowf`，版本 `1.60.1.70790`；应用 Info.plist 同步显示该版本。
- 正式无限目录为 `_forever_`，另有 `_cn_beta_`。本次两个插件只安装在正式无限目录。
- 本地 Leatrix Plus/Maps、Questie Forever/Camelot、DBM、Baganator 等 TOC 均包含 `16001`。这证明它们声明面向该接口，不等于已在本次会话验证其运行结果。
- 本地 Questie 的版本检测指出 Forever 与 Retail 共用 project ID，因此单靠 `WOW_PROJECT_ID` 不能可靠区分两者。

## 一手资料支持的实现选择

1. 原生 Forever 宏 UI 仍调用全局 `GetNumMacros`、`GetMacroInfo`、`CreateMacro`、`EditMacro`。`CreateMacro` 第四参数表示角色宏。容量使用 `Constants.MacroConsts`，源码声明账户 120、角色 30；实现从客户端常量读取，不硬编码槽位数。[原生 MacroUI](https://github.com/Gethe/wow-ui-source/tree/forever/Interface/AddOns/Blizzard_MacroUI)、[宏常量](https://raw.githubusercontent.com/Gethe/wow-ui-source/forever/Interface/AddOns/Blizzard_APIDocumentationGenerated/MacroConstantsDocumentation.lua)。
2. 原生宏文本框设为 `letters="255"`，并用 `GetNumLetters()` 显示长度，即字符限制。底层宏写入对 UTF-8 字节数的处理未获得可读实现，所以首版采用 255 字节保守限制并在创建后逐字比对。没有把字节限制写成游戏自身限制。[原生 MacroUI XML](https://raw.githubusercontent.com/Gethe/wow-ui-source/forever/Interface/AddOns/Blizzard_MacroUI/Blizzard_MacroUI.xml)。
3. 法术本使用 `C_SpellBook` 技能线与条目枚举；筛选普通主动技能、当前专精，并用 `IsSpellKnown` 检查学习状态。`IsSpellInSpellBook` 等接口的“在法术本中”语义不能直接等同于“已学”。只枚举玩家普通技能，未展开 Flyout 和宠物 bank。[原生法术本 API 文档](https://raw.githubusercontent.com/Gethe/wow-ui-source/forever/Interface/AddOns/Blizzard_APIDocumentationGenerated/SpellBookDocumentation.lua)。
4. 原生安全施法代码存在 focus/mouseover 路径，没有取得这些条件被无限服整体禁用的证据。具体宏解析与施法由游戏处理，尚未完成角色实测。不要把网上互相冲突的“姿态条件完全不可用”或“所有旧宏直接兼容”当成确定事实。[原生 SecureTemplates](https://github.com/Gethe/wow-ui-source/blob/forever/Interface/AddOns/Blizzard_FrameXML/SecureTemplates.lua)。
5. 官方开发说明记录了内置冷却管理、手柄宏移动修复及职业改动。这说明应针对当前客户端查证功能与技能名称；本版没有重复制作职业循环判断器。[暴雪无限服开发说明](https://us.forums.blizzard.com/en/wow/t/wow-forever-beta-development-notes-%E2%80%93-updated-november-2/2360696)。

GitHub 仓库是暴雪 UI 源码的第三方镜像，不是暴雪维护的官方仓库。已下载文件及哈希见 [SOURCES.json](upstream/SOURCES.json)，供日后比对更新；本次查询到 forever 分支 HEAD 为 `eac30af597e5aaa43a60f6675ef5fdcea100375f`。快照抓取自分支 URL，未声称与本机完整二进制逐文件一致。

## 第一版实现与限制

- **MyForeverMacros**：11 个固定用途模板，手动预览后创建普通角色宏；战斗中不创建或拾取，不修改原有宏，不设置按键；接口报错可退回手动复制。
- **MyForeverFieldKit**：只读查询金币、背包空位、耐久和位置，2 秒刷新一次；战斗期间暂停查询。没有自动消费、出售、修理或战斗执行逻辑。
- 通过 Lua 5.1 语法及 90 项模拟检查。未启动、登录或操作游戏角色；新插件识别、UI 外观、服务器规则、存档恢复和具体技能行为待客户端确认。
