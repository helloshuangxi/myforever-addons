# 最新版下载入口

2026-11-06

- 首屏与更新区使用明确的「下载最新版 v0.8.0 试用版」真实下载链接。
- 额外入口主文「下载最新版」，次文由版本数据生成「v0.8.0 试用版 · 87.4 KiB」。深青玉实色矩形，桌面至少 286×100，手机左右 20px、至少高 96px。
- 无 JavaScript 时，额外入口在页尾正常排版，仍可下载。
- 有 JavaScript 时，仅在主下载按钮不可见、不会压住标题/链接/按钮时浮动；位置与隐藏判定加 12px 安全余量。标题、图片链接、命令按钮和版本 summary 都受保护。
- 通过原生滚动事件的 requestAnimationFrame 和 IntersectionObserver 更新状态，不修改滚动行为。静止时没有计时轮播或闪动。
- 支持原生键盘焦点、按下反馈、减少动态效果与安全区域底部；打印时隐藏。焦点在入口内部时保持可操作，不自动隐藏。
- 页面底部保留 128px / 142px，锚点与控件有 150px scroll-margin-bottom，页尾可完整滚到入口上方。
- root/deploy_audit 是 HTML 与版本模板唯一写入者。前端样式与行为在 public/style.css、public/script.js；插入片段在 ops/下载按钮片段.html。

原固定版本被审查器发现手机标题经过底部时遭遮挡，且桌面压住「查看界面」。已撤回例外处理并修复，最终审查不使用 covered-text allow。
