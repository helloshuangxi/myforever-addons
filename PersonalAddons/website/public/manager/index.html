已经安装旧版管理器？目标选择需要 0.2.1 或更新版本。请下载并替换管理器程序，原有游戏目录、插件选择与自动更新设置会保留；进入设置页勾选“目标选择”并保存。管理器自身不会自动升级，游戏插件仍可按设置自动更新。

Mac 不确定选哪个？打开苹果菜单 →「关于本机」：显示“芯片 Apple M…”选 Apple 芯片版，显示“处理器 Intel…”选 Intel 版。

首次打开的系统提示：试用版尚未做 Windows 代码签名，Mac 版使用本地签名、尚未通过 Apple 公证。系统可能提示开发者身份无法验证；请先核对本页的文件名与 SHA-256。Mac 确认来源后，可参照 Apple 官方说明，在“系统设置 → 隐私与安全性”中对本程序选择“仍要打开”。也可继续手动安装插件。

第一次，只需选好目录

选择存放 _forever_ 的游戏文件夹，或直接选择 _forever_。管理器会识别对应的插件位置。

  1. 解压并打开程序。

    Windows 打开 MyForeverManager.exe；Mac 打开 MyForeverManager.app，可先移到“应用程序”。

  2. 选择你实际使用的游戏目录。

    支持选择游戏根目录、_forever_、Interface 或 AddOns。只管理识别到的无限客户端。

  3. 勾选插件，保存并开始管理。

    检查“自动更新”的选择。启用后，程序运行期间每 30 分钟检查一次；也可随时手动检查。

个人设置仍保存在游戏原有的 WTF 目录。管理器不会清理该目录。

更新时，会做好这些事

先核对，再安装

从本站获取版本信息与安装包，核对大小、SHA-256 与插件版本。下载失败或校验不通过时，不替换旧插件。

游戏中，先等等

检测到魔兽进程时暂缓安装，待游戏退出后重试。更新完成后，重新启动游戏加载新版本。

留一份旧版

更新前保留旧版插件，可在管理器中恢复备份。恢复会关闭自动更新，方便你继续使用旧版。

按你的选择管理

只处理勾选的本站插件。自动检查需要程序保持运行；关闭程序后停止，不会自动设置开机启动。

本版变化与验证范围

试用版会明确记录已完成的检查，以及仍需验证的环境。

本版变化

  • 午夜深色界面、统一卡片/按钮与状态反馈，四个插件保持独立选择、安装、更新和恢复。
  • 公开本机行为统计页：按角色与时间筛选日累计、技能及区域分布；需要手动安装同批MyForeverCoach采集器，统计不上传。
  • 保留既有目录、插件勾选、自动更新选择与本地统计；管理器自身需下载新包替换，不自动升级。

验证情况

.NET10 Release构建完成，Windows x64、Apple芯片Mac与Intel Mac三平台自包含包完成；两个Mac包通过本地临时签名结构校验。

原升级源码编译0警告/0错误，35项行为统计与68项安装/更新/备份/恢复隔离检查通过；不将隔离目录当作真实游戏安装验收。

Windows及Intel Mac未作原生真机运行；完整30分钟检查/退出游戏后60秒重试仍未完整等待；Windows未签名，Mac未做Developer ID签名与公证。

用户已验收游戏内界面并授权网站与app同步发布；没有把它扩写为Manager所有平台的视觉/操作验收。
