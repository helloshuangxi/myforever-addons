找 NPC：先用途，再细分

Questie 中可定位的 NPC 加入原有精选目录，按明确头衔与功能标记分类。职业训练师与专业训练师分别查找，专业入口按 12 种专业细分。声望与军需官、材料商人、特殊 NPC、常用服务及任务与其他 NPC 继续保留；商人、旅店、银行、拍卖、兽栏、修理和其他训练师也有细分。

支持名称、英文别名（数据提供时）、副标题与 NPC ID 搜索。按 NPC／地图去重，保留原精选标识；最近优先、名称排序、阵营与区域筛选继续保留，个人地点仍单独管理。

我的地点：常去的地方留下

收藏地点与自定义地点集中在同一页。“保存当前位置”“导入地图标记”也在这里；只有点击“新增地点”，才展开地图 ID、坐标和名称表单。

最多保存 500 个自定义地点，按角色记录。以当前目标命名时，保存的仍是玩家站立位置，不代表目标 NPC 的精确站位。

当前导航：专心看目标

单独查看 NPC、个人地点或临时任务目标的区域坐标、直线距离与追踪状态。独立方向框改为固定小尺寸的半透明框，只保留名称、箭头／方向、距离，以及地图、关闭两个按钮。客户端支持时启用原生任务或航点追踪。

跨大陆交通参考保留在“当前导航”页，方向框仅显示短状态；到达目标范围时提醒一次。箭头和距离不计算山路、楼层或最短步行路线，副本内暂停方向指引。

放进客户端，
从「导」字打开。

适配国服《魔兽世界：无限》1.60.1 / Interface 16001。当前为试用版，请先阅读验证范围。

使用插件管理器

  1. 从管理器下载页取得支持世界向导的最新版。
  2. 首次选择无限客户端目录，在插件列表选择“世界向导”。
  3. 退出游戏后安装或更新，管理器会检查下载包校验值。重新启动游戏并确认插件已启用。

旧版管理器若只显示聊天与商业技能助手，请先更新管理器。游戏内插件不会自行下载或替换文件。

手动安装 ZIP

  1. 完整退出游戏，下载并解压本页的试用包。
  2. 将 MyForeverNavigator 文件夹放到 _forever_/Interface/AddOns/。
  3. 保留 WTF，重新启动游戏，在插件列表启用“我的无限 · 世界向导”。

首次安装新目录需完整重启客户端；更新已经识别的插件后可重载。包内不包含玩家配置、聊天数据或第三方插件。要扩展 NPC 搜索，请另行安装并启用适配 Forever 的 Questie 与 QuestieDB；本次核对 Questie 12.8.0 / QuestieDB 1.1.0。

先选目的地，
再决定怎么走。

左键点击绿色方框里的「导」字，或输入 /mynav。窗口顶部选择“找 NPC”“我的地点”或“当前导航”。绿色按钮可拖动并按角色保存位置，右键停止导航。

从地图与任务列表找目标

打开大地图，先在右侧选中任务，再单击任务详情底栏、原生“追踪”旁的文字“导航”按钮。底栏四个按钮同排，原生追踪逻辑保留；沿用相同任务解析，有多个目标时仍弹窗选择。

不按修饰键，左键双击右侧任务追踪或任务日志中的同一任务；也可用 /mynav quest 查询日志中选中的任务。客户端任务下一站优先列出，离线参考补充任务 NPC、物品来源、任务物件与任务地点。只有一个可靠目标且进度明确时直接导航，多个目标或进度不明时打开每页 6 条的选择弹窗。

已选目标完成或阶段变化时停止旧指引，再点“导航”或双击任务，选择下一目标或交付地点；不会自动替换成另一个离线目的地。无可靠坐标时提示缺失，可打开“原生任务地图”。临时目标不写入收藏或自定义地点，不占 500 个地点名额，停止或重载后清理。新按钮的实际显示、物理点击，以及任务列表双击与真实任务行程尚未游戏实测；命令入口继续保留。

在“找 NPC”逐级缩小范围

进入角色后等待 Questie 就绪并完成分批读取，主目录标题会显示接入状态。左侧先选全部 NPC 或用途，再选具体职业、专业、声望、材料用途、服务或任务联系人；分类与结果都能翻页。输入名称、副标题、用途或 NPC ID 时，多个关键词需同时匹配。

分类旁数字是全目录记录数，不受阵营、区域或搜索条件影响。兼有制皮和裁缝用途的商人可出现在两个分组中。详情先显示姓名、用途与坐标；NPC ID、地图 ID 和说明放在默认收起的“更多资料”里。

查找九职业训练师

选择“职业训练师”，再按战士、圣骑士、猎人、盗贼、牧师、萨满祭司、法师、术士、德鲁伊筛选。默认浏览全部职业，也可继续按最近距离、阵营或区域缩小结果。

角色职业训练师与专业、宠物训练师分开；Questie 的“潜行者训练师”归入盗贼。普通专业训练师在独立专业入口，宠物等其他训练师可在常用服务中查找。资料读取不等于游戏站位实测；等级、费用与可学技能请在游戏内确认。

查找普通专业训练师

选择“专业训练师”，再选采矿、草药学、剥皮、炼金、锻造、制皮、裁缝、工程学、附魔、急救、烹饪、钓鱼。细分类每页 6 项，可翻页；选中 NPC 后使用“开始导航”“地图”或收藏。也可搜索“采矿训练师”“工程训练师”“炼金术”等关键词。

初级炼金师、高级铁匠、大师级技师及数据库提供的明确专精训练师按专业归组，需同时具备训练功能标记与明确头衔。材料、技能书商人不会因名称相似被当作普通训练师。已有部分进阶 NPC 保留特殊分类与原标识，也能从对应专业找到；不会重复新增点位。

名单不代表当前角色一定可学。等级、费用、阵营、已学技能与专精条件请在游戏中确认，插件不会自动学习。本版专业入口、物理点击、训练师站位及可教内容尚未游戏实测。

需要时再展开筛选与资料

“找 NPC”的“筛选”默认收起，展开后切换阵营与区域。默认本阵营、中立及双方敌对的怪物、整个世界；寻找另一阵营服务 NPC 时切换“阵营：全部”。“最近优先”按可比较的直线距离排列，也可切换名称排序。距离未知和跨大陆会明确标注。中立不代表初始友好，交互资格仍以游戏为准。

在“我的地点”保存与收藏

在“收藏地点”“自定义地点”间切换，分别搜索常去的 NPC 与个人坐标。点击“新增地点”才展开表单，填写地图 ID、X、Y、名称并“保存地点”；保存成功后表单收起。坐标填写 0–100，例如 55.9。

“保存当前位置”记录玩家站立位置；“导入地图标记”保存当前原生用户标记并开始导航，相同坐标会复用。没有有效标记时显示提示，不改变当前目的地。其他插件单独画的图标不一定能导入。

在“当前导航”查看行进状态

当前目标、区域、坐标、直线距离与原生追踪情况放在独立页面，提供“继续指引”“地图”和“停止导航”。关闭目录后，小尺寸半透明方向框只显示名称、箭头／方向、距离及地图、关闭两个按钮；不显示坐标、长说明或操作提示。箭头下以角色当前朝向为准标注“前、左前、左、左后、后、右后、右、右前”；关闭方向框仍会停止导航。

跨区、到达或无可靠方向时显示“跨区”“已到达”“暂无朝向”等短标签，框体保持固定尺寸，不编造前后方向。详细资料继续在“当前导航”页查看。0.3.3 曾观察到达状态的精简外观；本版新增数据库目录与导航操作尚待游戏验证。开始导航时客户端支持即可启用原生追踪，接口不可用、战斗或副本情形按提示处理。方向框正文不挡世界点击或右键转向，不显示悬停说明，名称区域仍可拖动保存位置。查看地图会收起目录；停止只撤销仍归本插件的追踪，不删除共享原生标记，也不干预玩家后来更换的追踪。

到达与距离的含义

每次开始导航后，首次进入目标坐标约 27 米范围时提醒一次。默认不播放声音、不自动删除标记，也不自动切换下一个地点。到达坐标附近不代表已找到 NPC 或可以交互。

本版不提供道路 ETA 或路线队列；方向和距离都不计算道路绕行与楼层。

资料与可达性

原 427 点精选底库继续保留；Questie 扩展数量随用户的数据库、客户端可识别区域地图与相位变化，不承诺全部 NPC。未知地图、无效坐标、副本区域和不可见相位不伪造成可用目的地。同一 NPC 有多个刷新点时，开始导航后固定所选参考位置，避免人物移动时跳到另一个点。

扩展目录只读本机 QuestieDB 的公开接口，不改变 Questie 设置，不随包分发其数据库或品牌素材。原精选与 3,817 个经典任务的部分离线参考来自 pfQuest MIT 数据，来源分别见 SOURCES.md。NPC 站位、商品库存、任务条件与可达性以游戏为准；本版扩大 NPC 搜索不代表所有任务目标均已覆盖。
