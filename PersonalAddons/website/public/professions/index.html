根据当前角色识别已学技能。常用信息留在眼前，展开细节时只显示一个专业。

进度始终在眼前

标题显示当前技能点与上限，进度条直观呈现比例。支持拖动、锁定、65%–160% 缩放，按角色保存位置与设置。

覆盖炼金、锻造、附魔、工程、制皮、裁缝、草药、采矿、剥皮，以及烹饪、急救、钓鱼。未学副专业也保留学习入口提示。

材料名，少打一遍

先点选搜索输入框，再 Shift + 左键点击材料，填入纯材料名；焦点在聊天输入框时，填入物品链接。

普通点击查看物品详情，悬停查看提示。材料输入不会自动查询或发送；实际拍卖行 Shift 点击尚未独立实测。

训练师，各有标识

面板显示训练师姓名、区域与坐标。地图用不同专业图标区分，靠近的位置分开排列，选中的图标缓慢闪烁。再点同一个训练师入口可隐藏图标，地图保持打开。

位置来自已安装的 Questie 与 QuestieDB 无限服数据，按阵营筛选。坐标是位置参考，可学内容以训练师窗口为准。

装好，打开你的专业。

适配国服《魔兽世界：无限》1.60.1，Interface 16001。当前为试用版，Windows 与 macOS 使用相同目录层级。

  1. 退出游戏，解压下载包

    找到解压后的 MyForeverProfessions 文件夹。

  2. 放入游戏插件目录

    将整个文件夹放入 _forever_/Interface/AddOns/。打开该文件夹应能直接看到 TOC 文件。

  3. 重启并启用插件

    首次安装请完整重启游戏，在插件列表勾选「我的无限 · 商业技能助手」。输入 /myprof 显示面板。

  4. 首次打开各项专业

    点击「打开专业」读取配方与材料。每个已学专业都需分别打开一次；关闭原生窗口后，助手仍保持显示。

训练师信息需要什么？

启用适配无限服的 Questie + QuestieDB，才能读取附近训练师。地图专业图标使用已安装插件提供的 HereBeDragons 图标库；没有图标库时保留坐标与原生地图标记。

发行包不包含这些第三方插件。专业识别、推荐与材料显示可独立使用。

已有版本怎么更新？

完整退出游戏后，用新包替换旧的插件文件夹，保留 WTF 目录以保留个人设置，再重新启动游戏。从旧版升级也建议完整重启，确保所有模块加载。

让它待在顺手的位置。

拖动标题移动窗口，使用右下角加减按钮或 Ctrl + 滚轮缩放。点标题右侧的减号收成与聊天按钮同尺寸的绿色「商」字图标，再点图标即可展开。「商」字图标始终可直接左键拖动，主面板锁定只限制标题；拖动松开不会误展开。

按橙、黄、绿选择练习

只推荐已学、可用、可涨点的项目，同色优先材料齐全的项目。红色、灰色、不可用及冷却中的项目不会进入推荐。

普通技能点没有可靠的内部经验或保证升级次数接口；标题显示当前点数／上限。客户端提供具体项目熟练度时，才显示还差多少熟练度。

从材料缺口准备下一次制作

每种材料显示单次需要量、背包已有量和缺口。可做次数只代表材料够用次数，不表示保证升级次数。采集项目不显示制造材料；采矿的熔炼配方仍显示所需材料。

重新打开专业，更新数据

背包、技能和配方变化时更新；战斗中暂停刷新。重载后暂用上次记录，打开原生专业窗口可重新确认配方难度。旧记录与读取范围说明可在项目悬停提示中查看。

靠近资源，看矿名与闪光

原生近距离接口识别到角色技能足够的矿石或草药时，提示框显示资源名和「就在附近」。矿石用金色、草药用绿色闪光，带深色描边、加大的亮点和柔光，方便在场景中辨认。即使客户端未生成资源姓名板，确认的原生交互目标也可提供文字和声音；闪光仍需真实姓名板。显示范围取决于客户端提供的交互目标，小地图有黄点不等于已进入此范围。

只读到无法定位的矿名时，显示「采集线索：铜矿」与「位置待确认 · 暂无方向」。这可能是旧悬停内容，不能据此确认附近仍有矿；线索状态不显示箭头，也不播放发现声音。

试用范围：已在 macOS 无限 1.60.1（build 70862）真实铜矿旁观察到自动「铜矿／就在附近」提示与描边闪光，矿点消失后自动清除。声音调用获客户端接受，实际听感尚未确认。无姓名板回退已通过模拟检查，现场未隔离验证。草药及其他地形待验证；完整小地图找矿和方向导航仍未恢复。

近距离确认资源时已接入一次提示音，持续可见时不反复响。可用 /myprof gather test 试听并预览箭头，用 /myprof gather mute 静音，/myprof gather unmute 恢复声音；自动触发已记录客户端成功调用，实际听感仍待验收。

提示框出现时，直接用左键拖框身移动，拖右下角斜纹手柄在 70%–130% 之间缩放，松开即保存。点主面板的「采集」或输入 /myprof gather move，没有资源时也能打开预览调整位置。

方向什么时候能自动出现？

开启角色已学的寻找矿物、寻找草药或寻找鱼群后，当小地图重新提供有效资源位置，插件会自动切换为名称和方向箭头，无需另开导航。这个自动切换已通过模拟检查，尚未确认当前客户端恢复定位；手动箭头预览也不代表真实导航已恢复。

如何关闭提示或调整闪光？

/myprof gather off 关闭文字提醒和自动声音，/myprof gather on 恢复。/myprof sparkle scale 1.2 将闪光调到 120%，支持 60%–160%。/myprof sparkle off 关闭闪光及其近距离文字、声音来源，/myprof sparkle on 恢复。

闪光会调整游戏的近距离交互目标设置。卸载前请先执行 /myprof sparkle off；插件会恢复仍由它控制的设置，并保留期间由你或其他插件修改过的值。

当前验证范围

11 个 Lua 文件语法检查、1254 项模拟检查通过（近距离专项 209 项）；独立复核另有 27 项断言通过，覆盖无姓名板识别、来源顺序、失败重试与声音去重。

macOS 无限 1.60.1（build 70862）中，加载相同功能源码的 0.4.6-dev.1 后，靠近并面向真实铜矿时自动出现“铜矿／就在附近”和金色描边闪光；矿点消失后提示与特效清除。客户端记录近距离声音调用成功 3 次，用户未留意实际声音，并明确以头顶提示出现作为本次验收标准。

无姓名板回退在模拟中通过，现场触发时可见姓名板闪光，尚未隔离实测该回退路径。可靠方向、实际声音听感、草药、更多地形及其他操作系统仍待验证；本版不代表完整小地图找矿恢复。
