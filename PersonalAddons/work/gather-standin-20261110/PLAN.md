# 纯名称采集扫描与替身地图本机实验

## Goal
在小地图原位置保留可辨认的地图画面与玩家箭头，后台以真实鼠标下的原生小地图提示读取矿草名称，自动弹出「附近有 名称」并按原声音设置提醒。包含站立时检测，不计算资源方向或导航。

## Constraints
- 用户2026-11-10已明确允许短暂隐藏／移动真实地图、要求替身画面；仅本机实验，旧“不搬图”限制对本实验解除，发布暂停仍生效。
- 不复制／分发NodeSight第三方实现，借鉴公开方法并基于已有自研退休实验重构。上游当前可静态核对的GitHub源码1.9.0与CF2.0.1公告分开记录。
- 不改键位、角色移动、角色追踪选择或采集提醒／声音／闪光开关；不触碰其他插件及WTF，不发布原始人物或聊天截图。
- 原有面板拉伸、字体稳定、固定技能书、材料Shift点击、Esc等UI保持冻结。
- 替身必须在移动地图前准备成功；缺少地图图像、受限位置或不支持的旋转状态时保留原地图、暂停扫描，不显示黑框／“扫描中”替代画面。

## Architecture / File changes
- `GatherStandIn.lua` +专项test：独立passthrough Frame，以公开C_Map地图图块为第一版本地图画面，裁剪到原小地图范围并画玩家箭头。接口 `Show(snapshot) -> true or false,reason`、`Hide()`、`IsShown()`、可选`Diagnostics()`；snapshot含原left/bottom/width/height/effective scale及map对象，在任何原地图变动之前调用。自己更新地图与玩家箭头，不生成矿点标记或导航。失败立即隐藏自己的画面并通知扫描器停止。
- `GatherCursorScan.lua` +专项test + `Textures/EmptyMask.tga`：真实光标不移动，原地图临时放到光标下逐帧读tooltip；空mask隐藏原生地面、跟踪并恢复原mask，不用alpha0以免黑色残影。只操作有明确恢复记录的框体输入／外观，不能盲目覆盖外部改动。所有出口先恢复真实地图，恢复成功才撤替身与发布新鲜结果。
- 扫描器接口 `ScanNames()`（新完成事务返回唯一name列表，未完成/暂停/错误nil，完成确认无矿为空table）、`Reset(reason)`、`IsSupported()`、`ScanDiagnostics()`，命名空间ns.GatherCursorScan。必须只消费一次新结果；禁止每0.1秒返回旧缓存并重新打时间。允许有新鲜确认矿名的短事务优先回报；空结果只能在完整覆盖并成功清理后发布。记录有效帧/控制点校验，拒绝无法证实的旧整图文字。
- `GatherScan.lua`保留原对象作为门面，按已保存实验模式路由新旧源，切换先清理恢复；旧单元测试在无新模块时仍覆盖原方式。
- `Core.lua/Main.lua/GatherAlerts.lua`与关联test：保存本机候选method，原on/off停止/恢复扫描；增加原方式回退命令；同值tracking事件不反复打断pass；沿用纯名称HUD与去重声音。TOC仅升dev版本，依次载入替身/新扫描器再HUD。
- 本机说明/验证/私有报告，不生成发行包或改网站。

## Step-by-step plan
1. 冻结当前dev7源码与验收证据，分离替身绘制、扫描事务、接入门面三个所有权。
2. 实现替身地图和纯名称扫描器；新图未准备好时不移动原地图；不支持旋转等场景明确暂停。
3. 定时站立扫描、公开值/tooltip容器检查、真实输入暂停、焦点边界、地图变化/超时/世界生命周期与失败恢复。小地图／按钮区域点击优先回归原地图。
4. 接回现有HUD名称/声音，验证正矿、无矿、缓存不续命、扫描饥饿、模式切换以及各种中断。保留1903项原回归，按新文件扩展模拟及语法检查并独立复核。
5. 观察当前游戏可用性，在不冲突情况下加载候选验证替身与真实矿点；新纹理需要完整重启时说明。不能把模拟、手动预览或客户端接受声音调用写成自动矿点与实际听感通过。

## Risks
- 原生tooltip在地图放到光标下一帧才变化；必须等待实际帧，不靠大量同步调用刷旧文字。
- 原地图原mask无Getter的客户端需跟踪Setter并使用已核实的标准mask回退；未知自定义形状不强行扫描，外部修改撤销本插件所有权。
- 新纹理资源可能需完整重启；加载失败不得隐藏真实地图。
- 第一次全覆盖可能有延迟；不能承诺任何操作状态下黄点出现的同一帧就提醒。站立时不应像作者默认定时方案那样永远不启动。
- 多个扫描插件可能互相搬同一Minimap；发现已知冲突应暂停并给出诊断，不能擅自关其他插件。
- 替身地图来自公开地图图块，可能与原生小地图配色/细节不同；第一版要明确是地图画面替代，不能声称像素一致。
