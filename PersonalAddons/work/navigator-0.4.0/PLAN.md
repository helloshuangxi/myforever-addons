# 世界向导 0.4.0 Questie NPC 目录接入

目标：让安装并启用的 Questie/QuestieDB 中可定位的 NPC 直接进入世界向导搜索、分类、收藏与导航。

约束：保留原427点、既有收藏ID、任务导航及300×84半透明HUD；不改Questie的locale/修正/设置，不分发Questie数据库；专业助手实验候选不发布。Questie未就绪时保留原目录，新增点位不冒充NPC实时位置。

文件：新增QuestieCatalog.lua及独立回归；Core.lua接入统一目录与延后ID恢复；Classification.lua服务类别；Provider.lua动态点解析；UI.lua主目录状态和用途布局；Main.lua分帧驱动；TOC与package_navigator.py名单；使用/来源/验证/网站和发版元数据。

步骤：1.核对安装数据库的公开API和时序；2.只读分批构建每NPC/地图一条的目录，去重精选点，过滤未知地图与无效坐标；3.按明确头衔/功能flag分类，接入搜索/收藏/导航并验证相位；4.真实数据库离线运行及模拟回归、可用时游戏观察；5.生成新版本包、同步官网和管理器，在独立冻结发布目录验证公网和旧包。

风险与验证：不把副本坐标投到世界地图；无可见相位不造位置；保留中立/敌对含义；避免每次搜索重读整库或在一帧构建。自动化验证与游戏观察分开记录，覆盖具体NPC缺失、晚加载、phase、同名/多地图、收藏重载、降级和错误恢复。
