# 商业技能助手本机优化计划

## Goal
训练面板以角色进度、推荐项目和材料缺口为主，操作与说明降级；增加直接缩放与 Esc 收起。对照 NodeSight 当前源码，只吸收满足现有约束的读取稳健性更新。

## Constraints
- 当前为私有候选，用户确认测试通过前不生成公开ZIP、不修改官网、不部署。
- 不移动、缩放或遮挡原生小地图，不增加导航、资源位置计算，不把旧悬停缓存当新发现。采集提醒/声音/闪光的用户设置保持不变。
- 保持橙→黄→绿推荐顺序、材料Shift插入、训练师地图开关及商字入口拖动/存储约定。
- WoW Forever原生Lua控件，保持现有游戏字体/图标；UI技能数据库本轮检索未命中适合WoW面板的精确层级条目，因此采用技能通用的信息分层、可读对比和非单靠颜色指示原则，不照搬Web/移动模板。

## File changes
- `_forever_/Interface/AddOns/MyForeverProfessions/UI.lua`：推荐与材料层级、辅助操作、缩放手柄、Esc生命周期。
- `PersonalAddons/tests/professions_ui_test.lua`：对应交互/布局回归。
- `GatherScan.lua`及其测试：公开返回值容器防护、真实鼠标位于小地图后代时暂停，保持原读取方法。
- TOC仅升本机开发版本；本机说明与验证记录同步，不触碰已发布包/官网。

## Step-by-step plan
1. 对照上游当前版本和本机UI/数据流，划清读取修复与实际报矿恢复。
2. 调整训练卡片：推荐名称突出、材料缺口清晰、次选与训练师次级，操作说明移至tooltip。
3. 复用65%–160%缩放存储，增加直接拖手柄与按钮备用；通过UISpecialFrames配合OnHide保存Esc收起，避免刷新自动重开。
4. 读取稳健性修改与UI实现分开所有权并行；完成有意义模拟、Lua语法与独立review，再观察可用真实客户端；无法实操项目明确待测。
5. 记录本机候选状态与准确验证范围，等待用户测试确认。

## Risks
- Esc只藏frame但没保存状态会被五秒刷新重开；需区分程序隐藏/祖先隐藏/用户Esc。
- 缩放拖动要固定左上角、保存与商icon兼容，并处理隐藏/窗口外松手。
- 长中文配方与物品链接可能遮挡计数，需长文字样本和完整面板视觉检查。
- 上游mask/移动修复不符合当前限制；读取健壮性改进不能等同当前原生接口已恢复。
