# 商业面板尺寸与固定技能书入口

## Goal
右下角拖动只改变窗口宽高与内容视口，字号不随拖动变化；打开技能书入口固定于面板顶部、不随内容滚动。

## Constraints
- 保持本机候选，用户确认前不打公开包、不修改官网、不部署、不自动启动或重载游戏。
- 本次只涉及面板布局与尺寸存储，不动采集检测、声音、闪光、键位及其开关。
- 保留推荐/材料层级、Shift物品插入、训练师toggle、商字图标拖动、Esc与异常松手收尾。
- 原 `/myprof scale` 作为明确的整体比例命令兼容保留，拖动手柄、±、Ctrl滚轮的常规窗口调整均改成宽高，不写字体比例。既有个人比例不强制重置。
- WoW原生Lua Frame。UI技能库未找到桌面窗口尺寸的精确条目；采用固定工具栏预留空间、内容重排等通用原则，不套Web组件。

## File changes
- Core.lua及core tests：共享尺寸范围/默认值，保存windowWidth/windowHeight的有限数值与边界校验。
- UI.lua及ui tests：响应式宽度、固定高度视口、直接二维尺寸拖动、固定顶栏按钮、释放与Esc生命周期。
- Main.lua及main tests：reset恢复默认尺寸；测试替身支持新增原生API，覆盖五秒刷新/重载尺寸契约。
- TOC、本机说明、验证与私有预览：更新候选版本与真实验证范围，不触碰发行包/网站。

## Step-by-step plan
1. 只读映射所有首次创建缓存的宽度、动态测高和现有专业打开语义。
2. Core定义PanelSize：默认372×474、宽340–900、高260–900；UI再按当前屏幕与实际比例限制最大尺寸。
3. 使用保存的窗口高度减固定96像素顶/底区域作为视口，宽度减边距得到内容宽度；更新所有缓存控件宽度后再测行高。内容不足时保留用户尺寸。
4. 手柄按鼠标x/y位移独立改变宽/高并保持物理左上角；±与Ctrl滚轮改为视口尺寸快捷调整。保留显式scale命令，footer显示尺寸。
5. 顶部第二行固定“打开技能书”。选中已学专业后启用，收起该专业时保留目标；选未学或尚未选择时禁用且明示状态，不暗开其他专业。移除卡片底部重复入口。
6. 针对字体不变/视口增加/长文重排/固定按钮/尺寸持久化/屏幕边界/Esc释放做有意义检查，集成全量与独立复核，生成标注清楚的模拟预览。

## Risks
- 只改外层尺寸但没有同步缓存FontString宽度，会导致重叠；需要统一重排后测高。
- 原Render会自动反写高度，必须改为持久视口并在刷新后保留用户选择。
- 非1 UIParent/面板比例下鼠标像素和UI尺寸要换算；屏幕钳制不能单独保证窗口不大于屏幕。
- 入口实际仍打开选定专业的原生配方/技能页，不是新增通用技能书API；禁用状态和上下文必须清楚。
- 当前无本轮实机证据；模拟字体/纹理与真正游戏不同，不能把模拟通过写成实测。
