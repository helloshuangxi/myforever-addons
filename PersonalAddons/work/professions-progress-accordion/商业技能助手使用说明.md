# 我的无限 · 商业技能助手 v0.2.0

本机试用版，适用无限服 **1.60.1 / Interface 16001**。已经放入 `_forever_/Interface/AddOns/MyForeverProfessions`。没有改动已有商业技能插件、角色配置、宏或按键。

## 开始使用

1. **完全退出并重新启动游戏**，在角色选择界面的插件列表启用「我的无限 · 商业技能助手」。这是新增插件目录，单独 `/reload` 不保证被发现。
2. 进入角色后常驻显示面板；输入 **`/myprof`** 也能显示。
3. **点击专业进度条展开详情，再点“打开专业”**，首次打开原生专业窗口后读取该角色已学配方或采集项目。展开一个专业时自动收起其他；再次点击当前条可收起。关闭原生窗口后，助手继续显示。
4. 拖动标题移动；右下角 `− / +` 或 **Ctrl + 滚轮** 缩放；标题「锁定」固定位置。普通滚轮浏览全部专业，标题 `−` 折叠为小条。位置、缩放、显隐、锁定、折叠和配方记录按角色保存。

## 面板内容

- 自动识别当前角色：炼金术、锻造、附魔、工程学、制皮、裁缝、草药学、采矿、剥皮、烹饪、急救、钓鱼。主要专业只显示已学的；烹饪、急救、钓鱼始终有入口，未学显示“未学习”和空条，展开可查看训练师提示。角色数据尚未读到时显示正在读取，不抢先认定未学习。
- 每个专业用经验条样式呈现：图标和名称在左，真实技能点／当前上限在右，填充比例为当前点数÷当前上限；未知数据不填假进度。展开详情后显示距上限差多少点、下一技能点目标。满当前上限时提示向训练师查看下一阶段。该进度条是专业技能点进度，并非下一点的内部经验。
- 只推荐本角色已学、可用、能涨点的项目，顺序固定为 **橘红色（橙）→黄色→绿色**。灰色、不满足条件、冷却中的项目不参与推荐。同色先列随身材料齐备的项目，再按材料可做次数与名称排序。不是拍卖行成本排序。
- 每个专业显示前三个推荐；点选候选可以查看对应材料。材料按**制作一次**显示「需要／随身已有／缺少」以及当前材料可做几次。银行和战团银行不算随身材料；可选材料不算必需材料；替代材料不被重复要求。
- **材料名称是可点击物品链接**：悬停查看原生物品说明，普通点击打开物品详情；Shift＋点击把链接插入已经打开的聊天输入框，不自动打开输入框或发送消息。备选材料逐个提供链接；缺少物品ID时显示普通文本，不伪造链接。物品缓存到齐后会刷新名称和品质颜色。
- 采集项目沿用客户端给出的真实难度颜色，展示训练项目；采矿的熔炼配方照常显示制造材料。客户端没有提供具体项目时显示该专业练习提示。
- 客户端提供项目熟练度时，显示该项目升下一级还差多少熟练度。普通专业技能点并没有可靠的内部经验或剩余制作次数接口，因而显示下一点目标和上限差值，**不会把材料可做次数写成保证升级次数**。

## 刷新和缓存

背包变化后刷新材料；技能涨点、学习新配方、打开或切换专业时重新读取。每 5 秒在可见状态下检查材料和已知冷却，战斗时保留面板并暂停数据更新，脱战继续。

不同专业需要分别首次打开。换角色使用该角色独立记录；重新登录或技能改变后，无法重读的专业会显示「上次记录 · 当前颜色待确认」，点击该专业刷新后才标为当前数据。查看别人链接、公会列表或 NPC 制造窗口时不采集为自己的配方。

优先读取全部配方接口；如果客户端只提供过滤后的列表，会保留已读项目并明确提示范围。此时可在原生专业窗口取消搜索或筛选，然后点击助手「刷新」，让更多项目进入推荐。助手不修改原生筛选条件。

## 命令

| 命令 | 作用 |
| --- | --- |
| `/myprof` 或 `/商业技能` | 显示面板 |
| `/myprof hide` | 隐藏面板 |
| `/myprof lock` | 锁定／解锁位置 |
| `/myprof scale 1.2` | 设为 120%，支持 65%–160% |
| `/myprof reset` | 恢复默认位置、大小并显示 |
| `/myprof refresh` | 刷新当前专业和随身材料 |
