# MyForeverProfessions v0.4.5 试用版验证摘要

发布日期：2026-11-08。适配国服魔兽世界：无限 1.60.1 / Interface 16001。

## 本次发布范围

采集功能基于本机 0.4.5-dev.5 源码发布；另修复主面板锁定时“商”图标无法拖动的问题。图标始终可直接左键拖动，松开不会误展开，丢失停止事件或隐藏时保存位置。新增近距离矿草描边大闪光、近距离文字及声音、无定位矿名线索，并预先接好有效位置恢复后的方向切换。专业识别、推荐、材料链接、训练师和拖动缩放功能继续保留。

用户已明确授权先公开附近提示版本供大家试用，完整自动找矿与方向恢复不在本次完成声明中。

## 自动检查

11 个生产 Lua 文件通过 Lua 5.1 语法检查，1167 项模拟检查通过：API/events 188、Core 96、Display 13、GatherAlerts 73、GatherScan 88、GatherSparkles 122、ItemLinks 82、Main 136、TrainerPins 162、Trainers 69、UI 138。开发阶段另完成独立只读复核与 4 项边界断言。

覆盖异常大范围命中过滤、三种提示来源切换、专业门槛、声音去重及失败重试、关闭/战斗/死亡清理和位置恢复后的自动接管。模拟检查不能证明游戏接口已恢复，也不能证明玩家实际听到声音。

## 已有游戏实测

在 macOS 无限 1.60.1（build 70862）中分别完成：

- 近距离铜矿的深色描边、大闪点、柔光及动态效果；开关、100%/120% 大小和重载保存。
- 无有效定位时显示“采集线索：铜矿 / 位置待确认 · 暂无方向”，文字完整且无箭头；提醒关闭隐藏、开启后恢复。
- 手动测试显示方向预览，五秒后回到线索状态。此项仅验证绘制，不是实矿导航或自动声音验收。
- 早期版本的提示框直接拖动及右下角缩放，由用户真实操作确认正常。

上述显示实测来自相应开发版，发行版没有修改采集功能源码；图标拖动修复本轮新增 20 项模拟回归，未新增游戏内鼠标实测。

## 当前限制

- 2026-11-07 游戏更新后，小地图查询仍可能在不同位置返回同一旧矿名，可靠自动定位与方向尚未恢复。
- 仅矿名线索可能来自旧提示，不能证明附近仍有资源；不会触发发现声音或生成方向。
- 当前近距离“就在附近”文字分支、自动声音触发与实际听感尚未完成矿旁验收。声音功能属试用，不声称已经听到。
- 有效坐标恢复后的自动导航切换只通过模拟检查，新的客户端接口变化可能仍需适配。
- 草药、更多地形、更远距离和其他操作系统尚未覆盖实测。

## 包内容与安装

ZIP 仅含 MyForeverProfessions 插件代码、MIT 许可、使用说明和本摘要，不含 WTF、SavedVariables、角色配置、聊天数据、诊断脚本或第三方插件。新增模块需要完整退出游戏后更新并重新启动。

近距离闪光会调整说明书所列的原生交互设置；卸载前先执行 `/myprof sparkle off`，恢复本插件仍拥有的修改。
