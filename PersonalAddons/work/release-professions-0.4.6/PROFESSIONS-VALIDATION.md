# MyForeverProfessions v0.4.6 试用版验证摘要

发布日期：2026-11-08。适配国服魔兽世界：无限 1.60.1 / Interface 16001。

## 本次更新

原生交互目标已确认可采资源时，不再要求必须存在资源姓名板才提供文字与声音。闪光仍依靠真实姓名板；没有新增或伪造坐标。改进匿名目标与可识别目标之间的声音记录归属，分别显示闪光数与近距离资源数。

## 自动检查

11 个生产 Lua 文件通过语法检查，1254 项模拟检查通过，其中近距离专项 209 项。独立只读复核通过，另有 27 项断言验证无姓名板识别、两种来源顺序、失败／冷却／静音恢复、相同身份不重复与不同身份提醒。模拟检查不能证明原生接口已经恢复，也不能证明玩家实际听到声音。

## 本轮游戏实测

在 macOS 无限 1.60.1（build 70862）加载 0.4.6-dev.1，功能源码与发行版一致，发行时仅调整版本标记。

靠近并面向真实铜矿时，自动出现“铜矿／就在附近”提示和金色描边闪光，未使用预览或伪造输入。随后矿点消失，提示与特效清除。客户端声音调用成功计数为 3，实际听感未确认。用户明确以头顶提示出现作为本次验收标准。

无姓名板回退路径已通过模拟检查；该次现场触发时可见真实姓名板闪光，未单独隔离实测回退路径。小地图悬停产生的“采集线索”与此次原生近距离触发分开记录，前者不能作为自动找矿成功证据。

## 当前限制

- 小地图范围的可靠矿草定位与方向尚未恢复；有黄点不代表已进入原生近距离识别范围，距离、朝向和地形可能影响客户端目标。
- 仅有无法定位的矿名线索时，不确认附近仍有矿，不触发发现声音或箭头。
- 声音调用成功不等于实际听感通过，草药、更多地形和其他操作系统未实测。
- 有效坐标恢复后的自动导航切换通过模拟检查，新的接口变化可能仍需适配。
- 0.4.5 的商字图标拖动修复沿用，游戏内鼠标验收待补。
