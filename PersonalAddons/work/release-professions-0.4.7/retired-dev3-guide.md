# 我的无限 · 商业技能助手 v0.4.7 试用版

适用无限服 **1.60.1 / Interface 16001**。本版增加小地图资源名称扫描，头顶显示「附近有 铜矿」，保留专业推荐、材料缺口、训练师位置和近距离矿草闪光。

**试用范围：本机 macOS 无限 1.60.1（build 70862）中已观察到原地重载后自动铜矿提示，客户端接受了提示音调用。最终显示修复已观察到无光标旁地图残影，扫描连续完成 6 轮并提示铜矿；右键验收尚待完成；此文件为私有候选，未公开发版。**

## 开始使用

1. 完全退出游戏，将解压后的 `MyForeverProfessions` 文件夹放入 `_forever_/Interface/AddOns/`，保留 WTF，再重新启动游戏。在角色选择界面的插件列表启用「我的无限 · 商业技能助手」。从旧版升级时也建议完整重启，确保所有模块加载。
2. 进入角色后常驻显示面板；输入 **`/myprof`** 也能显示。
3. **点击专业经验条展开详情**，其他专业自动收起；再次点击同一条可收起。展开后点独立的「打开专业」按钮，首次打开一次原生专业窗口，读取该角色已学的配方或采集项目。关闭原生窗口后，助手继续显示。
4. 拖动标题移动；右下角 `− / +` 或 **Ctrl + 滚轮** 缩放；标题「锁定」固定位置。普通滚轮浏览全部专业。点标题右侧 `−` 可收成与聊天按钮同尺寸的绿色「商」字图标，点图标或输入 `/myprof` 展开。“商”字图标始终可直接左键拖动，主面板的锁定只限制标题拖动；拖动松开不会展开面板。展开后的面板沿用新位置。位置、缩放、显隐、锁定、折叠和配方记录按角色保存。

## 面板内容

- 自动识别当前角色：炼金术、锻造、附魔、工程学、制皮、裁缝、草药学、采矿、剥皮、烹饪、急救、钓鱼。已学专业按客户端实际返回显示；烹饪、急救、钓鱼即使未学也保留条目，明确标为「未学习」，展开后提示向训练师学习。未学条目没有虚构的技能点或进度。
- 每个专业使用经验条样式，左侧是图标和名称，右侧是当前技能点／当前上限；填充比例反映这两个真实数值，不表示隐藏的内部经验值。点击只展开一个专业，保留其他专业标题条；内容过多时可滚动查看。
- 展开详情精简为训练师位置、推荐项目和材料；移除重复技能点、下一点目标、「上次橙」等文字标签，以及材料统计标题。难度继续由项目颜色表示。满当前上限时仍提示向训练师查看下一阶段。
- 只推荐本角色已学、可用、能涨点的项目，顺序固定为 **橘红色（橙）→黄色→绿色**。灰色、不满足条件、冷却中的项目不参与推荐。同色先列随身材料齐备的项目，再按材料可做次数与名称排序。不是拍卖行成本排序。
- 每个专业显示前三个推荐；点选候选可以查看对应材料。材料按**制作一次**显示「需要／随身已有／缺少」以及当前材料可做几次。银行和战团银行不算随身材料；可选材料不算必需材料；替代材料不被重复要求。
- 所需材料名称使用游戏物品链接：鼠标悬停查看原生物品提示，点击打开物品详情。**先点击拍卖搜索框等输入框，再 Shift + 左键点击材料**，即可在光标处填入材料名称；焦点在原生聊天输入框时插入物品链接。不自动提交搜索或发送消息；没有可用输入框时提示先选输入框。替代材料各自有链接；暂未缓存名称时按物品 ID 显示，连物品 ID 也未知时显示普通文本。
- 采集项目沿用客户端给出的真实难度颜色，展示训练项目；采矿的熔炼配方照常显示制造材料。客户端没有提供具体项目时显示该专业练习提示。
- 客户端提供项目熟练度时，显示该项目升下一级还差多少熟练度。普通专业技能点并没有可靠的内部经验或剩余制作次数接口；专业标题保留当前点数／上限，**不会把材料可做次数写成保证升级次数**。

## 小地图资源提醒

角色已学采矿或草药、当前有效技能点达到资源要求，并在小地图开启「寻找矿物」或「寻找草药」时，助手会自动扫描小地图当前显示的已知资源。确认后，头顶显示「附近有 铜矿」和「小地图范围内」，并按声音设置尝试播放一次地图提示音。此版本专注资源提醒，不显示方向箭头。登录、重载或重新开启提醒后，无需先移动角色即可开始扫描。

扫描采用原生小地图悬停读取。扫描期间原位置短暂显示「扫描矿草…」，结束后恢复真实小地图；按下鼠标、转动视角、鼠标覆盖其他窗口、战斗、死亡或切换地图时暂停并恢复。首次扫描会重新应用游戏当前布局里的图标大小；扫描中临时隐藏任务区域、坐标、图标及地图专属提示框，结束或取消后恢复助手仍拥有的修改。扫描速度受帧率与鼠标操作影响，持续操作时会延后，短暂一闪而过的资源仍可能错过。不同资源需要该角色实际学会相应专业；不会根据未验证的历史坐标或仅有旧文字提示来弹出“附近有矿”。

同名已知资源持续出现时不重复响；小地图和近距离来源共享声音回执，目录中的明确别名也共用回执。多个发现至少相隔 4 秒。离开至少 10 秒后再次确认资源可重新提醒。完成空扫描会清除小地图提示；被打断的扫描不会假装“已扫描为空”，缓存按原始确认时间过期。此版本不根据小地图读数猜测高度或路径。

`/myprof gather test` 显示五秒测试提示并按当前设置试听声音。用 `/myprof gather mute` 静音，`/myprof gather unmute` 恢复声音，`/myprof gather off` 或 `on` 关闭或开启提醒。开关按角色保存。`/myprof gather` 可查看已确认的资源种类、扫描次数与声音调用情况；调用成功不等于已验证实际听感。

提示框出现时，直接用左键拖动框身移动，拖右下角斜纹手柄可在 70%–130% 之间缩放。松开即保存。附近没有资源时，点主面板「采集」或输入 `/myprof gather move` 打开预览，调好后点「完成」。拖动或缩放时会暂停扫描，结束后继续。

## 近距离矿草闪光与声音（试用）

默认开启。客户端提供附近资源的原生交互姓名板后，在矿石上显示金色闪光、草药上显示绿色闪光。闪点带深色描边、加大的亮色核心和柔光，四颗闪点错开起伏，在雪地背景也更容易辨认；描边属于闪光标记，不是矿石模型的轮廓。只识别目录内名称，且要求角色已学对应专业、有效技能点达到门槛。未知物体、NPC、邮箱和鱼群不加特效。特效跟随原生姓名板，不拦截鼠标点击；战斗中暂停，脱战后恢复。

输入 `/myprof sparkle off` 关闭，`/myprof sparkle on` 开启，`/myprof sparkle scale 1.2` 调至 120%（支持 60%–160%）；`/myprof sparkle status` 查看状态。设置按角色保存。

v0.4.6 增加直接读取原生交互目标：即使客户端没有生成资源姓名板，只要原生接口确认资源名且角色技能足够，文字与声音仍可触发；闪光仍需要真实姓名板。状态命令分别显示闪光数量、近距离识别资源种类和声音调用成功次数。

识别到角色可采集的附近矿石或草药时，按声音设置尝试自动播放一次地图提示音。11 月 8 日在真实铜矿旁自动出现“就在附近”提示和闪光，声音调用成功计数为 3；这不等于已确认实际听到声音。相同可识别物体持续可见时不重复，短暂转向或姓名板闪断保留提醒记录；资源离开检测范围至少 10 秒后，再次发现可以重新提醒。多个发现的声音至少间隔 4 秒。无法取得可靠物体标识时按资源名保守去重，此时同名的相邻资源可能合并为一次提醒。重载后会重新识别当前附近资源，允许提示一次。

近距离文字与声音和原采集提醒共用开关：`/myprof gather mute` 静音，`/myprof gather unmute` 恢复声音；`/myprof gather off` 停止文字提示和自动声音但保留闪光，`/myprof gather on` 恢复提醒。关闭闪光也停止该来源的近距离文字和声音。声音使用游戏现有音效通道，需游戏声音开启；战斗中暂停。近距离来源只提示已被原生接口识别到的资源，不提供方向。

为了启用原生近距离交互目标，开启时设置 `SoftTargetInteract=3`、`SoftTargetIconGameObject=1`、`SoftTargetInteractArc=2`、`SoftTargetInteractRange=30`。请求范围不是保证可探测距离，显示取决于客户端实际提供的交互目标。关闭时，仅当当前值仍等于本插件所设值才恢复原值；期间用户或其他插件改过的值会保留。正常重载会保存恢复记录，异常退出且尚未保存时不能保证恢复。卸载前请先输入 `/myprof sparkle off`。

近距离识别也会提供「就在附近」文字提示，与原小地图提示框共用位置和大小。近距离闪光仍需客户端提供真实资源姓名板；小地图资源提醒独立按上述扫描流程工作。草药、不同地形及更远距离需要分别验收。

## 附近训练师

展开专业后以对应专业图标标出训练师，并显示姓名、区域和坐标。点击可打开对应地图。当图标可见时，再点同一个训练师入口可隐藏助手的训练师图标，地图保持打开。再次点击可恢复显示。地图上同时显示本角色各专业附近训练师的不同图标，位置相近时分开排列；选中专业图标缓慢闪烁，其他图标保持静态，不再叠加定位点或金框。悬停查看姓名及精确坐标。悬停可查看当前区域／附近区域范围、可用的直线距离和教学说明。急救、钓鱼等尚未学习的副专业也能查找训练师。

位置读取本机 **Questie + QuestieDB 的无限服数据**，按角色阵营过滤，优先当前地图，再比较同一世界坐标下的附近区域。两插件未启用或数据未加载完成时会明确提示。分类地图图标使用已安装插件提供的 HereBeDragons 图标库；缺少图标库时仍可查看文字坐标和原生地图标记。缺少距离换算时只列同大陆已知训练师，不声称最近；地图不能标记时打开区域并保留坐标供查找。坐标不等于行走路线；可学项目和技能阶段以训练师窗口为准。

## 刷新和缓存

背包变化后刷新材料；技能涨点、学习新配方、打开或切换专业时重新读取。每 5 秒在可见状态下检查材料和已知冷却，战斗时保留面板并暂停数据更新，脱战继续。

不同已学专业需要分别首次打开。换角色使用该角色独立记录；重新登录或技能改变后，无法重读的专业继续使用上次记录，其说明移到推荐项目的悬停提示中；展开该专业并点「打开专业」可更新当前难度。查看别人链接、公会列表或 NPC 制造窗口时不采集为自己的配方。

优先读取全部配方接口；如果客户端只提供过滤后的列表，会保留已读项目，并在推荐项目的悬停提示中说明范围。此时可在原生专业窗口取消搜索或筛选，然后点击助手「刷新」，让更多项目进入推荐。助手不修改原生筛选条件。
