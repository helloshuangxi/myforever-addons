# 我的无限 · 目标选择 0.1.46 试用版

适配国服《魔兽世界：无限》1.60.1，Interface 16001。本版发布已验证的友方脱战普通技能悬停兼容、焦点操作和紧凑面板，不包含本机未实测的姓名板缩放实验。下载与更新：https://afabiaoge.xyz/targets/ 。

## 安装与更新

完整退出游戏，将整个 `MyForeverTargets` 文件夹放入 `_forever_/Interface/AddOns/`，保留原有 WTF 和 SavedVariables，再启动游戏。包内已包含距离库。我的无限插件管理器 0.2.1 及以上可检查、安装和更新目标选择；更早的管理器须先替换新版程序。

更新保留已保存的面板位置和设置。仅未拖动过的旧友方默认位置会迁到屏幕左侧偏上，避让底部动作条。标题栏脱战拖动可保存位置；`/mytargets reset` 恢复面板与图标位置。

## 面板与操作

友方分团队 20 格、小队 5 格、附近 5／10／20 格；敌方单列表可选 5／10／20 格。附近按距离动态排序，悬停时暂缓所在名单重排。主格为 76×58，显示职业色姓名、整格血量及底部资源条，格间距 1 像素。敌人下方独立 76×26 目标条显示其目标的姓名、职业与血量。

- 左键选中目标，右键设置焦点，Ctrl+右键打开标记菜单。重复点击不取消目标或焦点。
- 当前目标以红框提示，当前焦点以黄框提示。焦点头顶另有动态菱形；鼠标悬停动画使用不同样式。有可见姓名板时才显示头顶效果。
- 标题右端“×”关闭对应面板；屏幕左侧玉绿色“目”字图标打开面板菜单，右键快速开关两侧，拖动可保存图标位置。战斗内面板开关在脱战后应用。
- 操作帮助显示在浮层。主格显示本人（含宠物、载具）施加的有时限 buff／debuff，友方还显示本人可驱散的 debuff；常驻光环、采集追踪不显示。每类一排，更多效果用滚轮查看，敌人的小目标条不显示效果图标。

## 脱战普通技能悬停兼容

鼠标停在友方格子上，按原来的普通治疗／增益技能键，可临时选中该单位施放后恢复原目标；原先无目标则恢复为空。两侧“施法”按钮控制同一开关，也可输入 `/mytargets legacycast on` 或 `off`。附近友方已有用户游戏实测成功并恢复原目标。

此功能仅支持脱战，会改变上一目标历史。它不是让所有附近格子自动成为游戏原生 `mouseover` 单位：玩家已有宏仍使用原按键，不接入临时选中施法桥；物品、鼠标技能键及其他插件占用的键也不接入。技能仍受距离、视线、朝向、冷却等规则限制。进入战斗会归还原键，不创建新的目标动作。

敌方及敌人的目标条保留相同兼容入口，但尚无完整施法成功验收；附近同名怪无法靠名称方式精确施法，识别不唯一时拒绝。不要将本版作为战斗中敌人格子的原生 `@mouseover` 施法方案。

## 焦点与同名怪

附近单位通常在脱战时按完整名字临时选中、设置焦点，再恢复原目标；自己、小队、团队保留原生单位动作。焦点操作独立于“施法”开关。

脱战右键同名怪格子可启动按 GUID 核验的流程：按格子或中央按钮的提示继续右键，每次真实点击推进一次选敌；插件只在 GUID 命中后准备焦点确认，随后恢复原目标。默认把“确认焦点”和第一步恢复合并，通常少一次点击。看到“尚未完成”需继续右键；只有焦点和原目标都核验匹配才显示完成。

寻找过程中原焦点保留，目标会暂时变化。进入战斗或出现待施法光标时暂停；手动更改目标或焦点会停止流程；重载不会续接未完成流程。找不到或无法恢复时不会冒充完成，可自行恢复目标。`/mytargets focuscycle restore` 准备重试恢复，`stop` 停止并保留当前目标。`staged` 可在无进行中流程时切到分步恢复，`combined` 返回合并模式；模式仅本次会话生效。

战斗中任意附近敌人／同名怪按 GUID 自动匹配并设置焦点仍未解决，本版不提供该保证。已验证的合并成功场景为非空原目标；空原目标的分步模式有实测，合并模式仍待单独验收。详见包内 `VALIDATION.md`。

需要排查时可输入 `/mytargets log start`，操作后 `/mytargets log stop`，再 `/reload` 保存。日志留在本机，不包含于下载包。第三方来源及许可见 `Libs/SOURCES.md`。
