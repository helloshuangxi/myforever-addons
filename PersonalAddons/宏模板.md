# 个人宏模板

以下对应 MyForeverMacros v0.1.0。四个通用宏可直接复制到 `/macro`，其余请用插件选择本角色已学技能。适配目标为本机无限服 1.60.1.70790；语法与接口已核查，施法效果待游戏实测。

## 直接可复制

### 设置焦点／Alt 清除

鼠标下存活单位优先，没有则取当前存活目标；Alt 只清除，不会随后重新设置。

```text
/clearfocus [mod:alt]
/stopmacro [mod:alt]
/focus [@mouseover,exists,nodead][@target,exists,nodead]
```

### 跟随友方

鼠标下友方优先，否则当前友方。实际跟随仍须符合游戏对目标、距离等要求。

```text
/follow [@mouseover,help,nodead][help,nodead]
```

### 宠物攻击／Shift 召回

普通按键攻击当前敌人；Shift 设为被动并跟随。召回后保持被动态度。

```text
/petpassive [mod:shift]
/petfollow [mod:shift]
/stopmacro [mod:shift]
/petattack [@target,harm,nodead]
```

### 上方饰品／Shift 下方饰品

```text
#showtooltip
/use [mod:shift] 14; 13
```

## 需要填写技能的模板

`技能一`、`技能二` 是占位文字，不能原样使用。插件会从你的法术本选择实际名称并替换。

### 鼠标指向敌方

```text
#showtooltip
/cast [@mouseover,harm,nodead][harm,nodead] 技能一
```

### 鼠标指向治疗／Alt 自己

```text
#showtooltip
/cast [mod:alt,@player][@mouseover,help,nodead][help,nodead][@player] 技能一
```

### 焦点打断／Shift 当前敌人

注意：先取消自己的读条，再尝试施放打断。

```text
#showtooltip
/stopcasting
/cast [mod:shift,@target,harm,nodead][@focus,harm,nodead][harm,nodead] 技能一
```

### 焦点控制／Shift 当前敌人

```text
#showtooltip
/cast [mod:shift,@target,harm,nodead][@focus,harm,nodead][harm,nodead] 技能一
```

### 近战技能与普通攻击

```text
#showtooltip
/startattack [harm,nodead]
/cast [harm,nodead] 技能一
```

### 光标处地面技能

落点直接采用鼠标所在位置，不再二次确认。只能用于地面指向技能。

```text
#showtooltip
/cast [@cursor] 技能一
```

### 普通技能／Shift 另一技能

```text
#showtooltip
/cast [mod:shift] 技能二; 技能一
```

若一个匹配的目标超出射程或被遮挡，宏不会因施法失败再回退目标。技能仍受资源、冷却、姿态、装备、学习状态等限制。
