# 牧师个人宏：v0.2.0

已按你的牧师职业定制。重启客户端，启用 MyForeverMacros 后输入 **`/mypriest`**。原有随身手册继续用 `/myfield`。

左侧选用途，插件会在**当前角色已学的主动技能**中寻找对应法术。找到后填入真实技能名称，再由你查看宏内容并点击创建。没有学会或接口无法确认时保持空白，不会把“能查到技能资料”当成“已经学会”。可用“从法术本选”手动调整。

| 预设 | 操作 |
| --- | --- |
| 真言术：盾 | 鼠标下友方优先，其次当前友方、自己；Alt 强制自己 |
| 恢复 | 同上，用于持续治疗 |
| 常规治疗 | 选择预设时，依次寻找已学强效治疗术、治疗术、次级治疗术；目标规则同上 |
| 快速治疗 | 同上；未学会时留空提示 |
| 友方驱散 | 只对友方／自己施放驱散魔法，Alt 自己 |
| 敌方驱散 | 鼠标下存活敌人优先，否则当前存活敌人 |
| 祛病术 | 友方／自己；不与驱除疾病混写 |
| 复活术 | 仅非战斗，鼠标下死亡友方优先，其次当前死亡友方 |
| 暗言术：痛 | 鼠标下存活敌人优先，否则当前存活敌人 |
| 惩击 | 同上 |
| 渐隐术 | 按键施放；不自动打断当前读条 |

先用**盾、恢复、常规治疗、友方驱散**熟悉操作即可，不需要一次把所有宏放满动作条。只有技能确实学会，且满足游戏的施法条件，宏才会生效。

所有治疗宏都没有默认加入 `/stopcasting`，连续按键不会因为这条命令取消自己的治疗。鼠标指向宏不改变当前选中目标。请优先使用键盘绑定验证；部分鼠标侧键在单位框体上可能被框体的点击绑定拦截。

友方宏包含自疗兜底：鼠标和当前目标都没有有效友方时会尝试对自己施放。驱散不会自动判断目标有没有可驱散效果。匹配到的目标超出射程或被遮挡时，不会再自动回退到下一个目标。

常规治疗的优先次序只是生成宏时的初始选择，不表示最省蓝或最适合每次受伤量。你可以手动选择另一种已学治疗法术。学习新的治疗法术后，重新选择预设会读取新法术本；**已有宏不会被自动覆盖**，可在 `/macro` 修改，或换一个宏名创建。

## 两个直接可复制的例子

以下使用简体中文常见名称；以你自己的法术本名称为准。

真言术：盾：

```text
#showtooltip
/cast [mod:alt,@player][@mouseover,help,nodead][help,nodead][@player] 真言术：盾
```

恢复：

```text
#showtooltip
/cast [mod:alt,@player][@mouseover,help,nodead][help,nodead][@player] 恢复
```

尚未在你的角色中实测加载、字体、中文宏保存或施法。模拟测试验证插件逻辑，不能替代游戏验收。当前版本兼顾基础治疗与练级；未假定你是神圣、戒律或暗影，也没有预设需要特定天赋、种族的技能。
