# 骑士：正义圣印与审判

2026-11-06，本机 MyForeverMacros v0.2.2，目标客户端 wowf 1.60.1.70790 / Interface 16001。

## 手动粘贴宏

打开 `/macro`，将「正义审判」正文替换为：

```text
#showtooltip
/cast [mod:ctrl] 正义圣印; 审判
```

普通按键释放审判；按住 Ctrl 再按宏的按键补正义圣印。松开 Ctrl 后再按即可审判。没有自动判断、等待或自动施法。

Ctrl 与该按键的组合如果已经绑定了其他功能，需要在按键设置中解除冲突，或者用 Ctrl + 鼠标点击宏验证。不指定等级，交由客户端选用技能等级。此次按用户要求只提供宏正文，不修改游戏内旧宏或动作条。

当前时光服审判的技能说明写明不会消耗圣印，因此圣印仍在时只需要使用审判。

## 淡出提醒

提醒附加在已经安装的「MyForever 个人宏工坊」中。重新进入角色，或已在线时输入 `/reload` 加载。插件列表中须启用 MyForeverMacros。

只在已学会正义圣印的圣骑士角色上生效。圣印缺失时，屏幕中央偏上显示小图标、暖金色「缺少正义圣印」和 Ctrl 补圣印提示。背景缩成两端渐隐的半透明窄条，无大块黑底或顶部粗线。

提示用0.2秒淡入、停留2秒、再用1.3秒逐渐淡出，总共3.5秒。一次缺失只提醒一次，消失后不常驻，也不会因为其他增益或状态事件重复弹出。补上圣印会立即结束真实缺失提醒；之后圣印再次消失，才触发下一次。

登录时已经缺少圣印也会短暂提示，战斗内外均检查。死亡、灵魂状态、乘坐飞行交通工具与载入期间立即隐藏，恢复后缺失可再提醒一次。提示不拦截鼠标点击；动画结束后不再逐帧更新。

- `/myseal test`：预览同样的3.5秒淡入淡出；结束后即使缺失也不会紧接着再弹一条。
- `/myseal off`：关闭本角色提醒。
- `/myseal on`：重新开启本角色提醒。

开关按角色保存。检测只负责显示提醒，不会替玩家施法，也不修改宏或按键。
