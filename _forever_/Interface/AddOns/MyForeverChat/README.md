# 我的无限 · 微信式聊天 0.10.2 试用版

适配国服《魔兽世界：无限》1.60.1，Interface 16001。
完整退出游戏后，仅将 MyForeverChat 文件夹复制到 _forever_/Interface/AddOns/，保留 WTF，重新启动。

## 快速回复

- 点击新消息泡泡或按 Ctrl+X，打开紧凑回复小窗；/wx reply 回复最近的角色或通行证私聊。
- 确认标题中的收件人后输入文字，Enter 或「发送」提交；新来信不会自动切走当前收件人。
- Esc、关闭或再次 Ctrl+X 收起小窗，草稿保留；主聊天窗口打开时 Ctrl+X 仍先最小化。
- 点「展开」进入同一会话的完整记录，草稿一起带过去；/wx 或「聊」也可打开完整窗口。
- 明确离线时不能发送。未知状态会标明；未确认时禁止重复提交，私聊超时需先点「允许重试」。关闭窗口不自动重发。
- 角色及战网私聊以游戏回显确认后清空原文；等待期间新写的草稿保留。群聊成功仅表示已提交，展开后可找回上次发送。
- 消息提醒从屏幕右下角出现，整组随条数向上展开，优先顺序与翻页规则保留。
- 快速回复每次从当前「聊」图标处展开，靠边时向屏幕内侧调整；单次打开仍可拖动，下次打开会回到图标处，图标本身不移动。旧的独立小窗位置不再决定打开位置。聊天字号跟随外观设置。支持先聚焦小窗输入框再 Shift 点击背包物品插入链接。

/myui 打开统一布局，/myui sound 切换菜单音效。已有位置、主题和会话设置保留；聊天旧用户可在设置选择「午夜」。共享样式随插件内嵌，无需额外安装。Ctrl+X 只作会话内临时快捷键接管，不写入保存的按键配置。

0.10.0 星辉外观沿用用户既有界面验收；本版位置调整与快速回复的验证范围见 VALIDATION.md，模拟检查不等于真实消息投递已通过。
