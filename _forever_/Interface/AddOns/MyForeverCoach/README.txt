我的无限 · 玩家行为采集 0.2.0 本机候选

用途
在玩家实际游玩时，累计当前角色可观察的公开游戏行为，并在我的无限软件的“行为统计”页进行本机分析和展示。
本版不连接 AI，不上传数据，不操作角色、键位、镜头或小地图。
新代码已做模拟检查；0.2.0 新增行为累计尚待当前客户端 /reload 后实测。

安装与加载
目录仍为 _forever_/Interface/AddOns/MyForeverCoach，兼容原存档与 /mycoach 命令。
游戏正在运行时，磁盘代码变更需 /reload 后生效；若新增文件未加载，请正常退出并重新启动游戏。
/mybehavior 打开今日行为概览，“能力检测”按钮切换到原检测矩阵。
我的无限软件从本机读取此插件专属 SavedVariables，不需要手动复制导出 JSON。
客户端通常在 /reload 或登出后写盘；软件刷新只能看到已写盘的数据。

常用命令（旧 /mycoach、/mfcoach 仍可用）
/mybehavior              今日行为概览；隐藏不影响采集
/mybehavior hide         隐藏面板
/mybehavior pause        暂停采集；暂停期不累计游戏行为
/mybehavior resume       恢复并重建状态与经验基线，不补算暂停期间的操作
/mybehavior diagnostics  能力检测矩阵
/mybehavior probe        检测当前场景
/mybehavior new          脱战后新建明细会话；日累计继续
/mybehavior export       可复制 JSON，包含明细及受控日累计字段
/mybehavior report       能力诊断摘要
/mybehavior log status   查询系统战斗日志状态
/mybehavior log on/off   仅在玩家明确输入时切换客户端系统战斗日志

统计口径
按 UTC+08:00 分日，保留最近 90 天摘要。采集时长只含采集开启且插件加载期间；暂停时长单独保留，不计入采集时长。
战斗、非战斗与状态未知时间按公开状态分开；不把副本/PvP直接当作战斗。
战斗进入/结束按状态变化去重；重载时已经处于战斗不会虚增一次进入。
施法开始、成功、失败、中断分别统计，只接收通过玩家单位与技能ID检查的事件；“失败”不代表误操作。
死亡只统计 PLAYER_DEAD，去重直至观察到复活事件；PLAYER_ALIVE/PLAYER_UNGHOST 不当作死亡。
经验采用连续公开快照差分；跨一级使用上一级剩余经验加新等级经验。缺基线、跨多级或受限时保留缺口，不推算不存在的数据。
任务接受与交付分别统计，不将任务奖励经验再次叠加到经验差分。
地图停留使用公开 mapID；首次观察与地图变化计一次访问，不计算移动距离、击杀数、挂机、输出量或漏打断率。
技能/地图名称只来自公开 API，缺失或受限时只保存 ID；每个日技能表与地图表各最多 128 项，超额影响明细分布而不影响行为总计。

容量与隐私
兼容根 schema=1，原会话保持最多 8 个，每会话 1200 条诊断明细、12 项错误。
日累计独立于明细上限，满 1200 条仍累计行为和时长；detailDropped 标记省略的明细。
技能/地图分布上限分别由 spellOverflow/mapOverflow 标记，不混作原始明细丢弃。
只保存白名单公开数值、技能ID、任务ID、地图ID/坐标，以及公开技能/地图名称。
不保存角色姓名、账号、战网信息、GUID、聊天、按键输入。无网络请求或外部 AI 调用。
受限值在比较、计算、保存与导出前丢弃；不会暂存 secret 值等待脱战解密。
继续停用 COMBAT_LOG_EVENT_UNFILTERED 注册与 CombatLogGetCurrentEventInfo 读取。
客户端拦截本插件接口时，先结算已采集时间，再锁定安全停采；本次加载不能强行继续，需要修复并重载。
能力诊断的事件收件计数不是玩家行为次数，暂停时可以继续保留纯事件名计数，不保留事件操作内容。

实测建议
重载后确认 /mybehavior 显示 0.2.0；手动施放几种技能、打一场安全普通战斗并暂停/恢复一次。
如能完成任务或升级，再核对相应日统计；没有发生的项目保持未验证。
输入 /reload 让客户端写盘后，在我的无限软件刷新行为统计。不要把模拟检查当作游戏实测。

卸载
在插件列表停用本插件，或退出游戏后移走 MyForeverCoach 目录。
本机历史位于当前角色 SavedVariables/MyForeverCoach.lua，卸载不会自动删除；软件本机归档另行保留。
