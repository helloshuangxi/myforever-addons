# 我的无限 · 世界向导 0.4.1 试用版

更新日期：2026-11-13。

适用国服 Forever 客户端 1.60.1（Interface 16001）。内置精选目录、任务参考和个人地点可独立使用；要扩展搜索 Questie 数据库里的 NPC，需要同时安装并启用适配 Forever 的 Questie 与 QuestieDB。本次接入核对版本为 Questie 12.8.0、QuestieDB 1.1.0（contract 4）。不要求安装 TomTom。

## 开始使用

插件已放入当前客户端的 `Interface/AddOns/MyForeverNavigator`。这是新增插件目录，首次使用请完全退出并重新打开游戏，在角色选择界面的“插件”列表确认“我的无限 · 世界向导”已启用。不会自动退出正在运行的游戏。

本次本机源码已更新；当前角色空闲且脱战时可输入 `/reload` 加载新入口。本轮未替玩家重载或执行专业训练师操作验收。

进入游戏后输入 `/mynav`，或左键点击绿色方框里的“导”字。按钮与聊天“聊”、商业技能“商”同为 42×42 的绿色方框，新装默认位于右上区域；已拖动过的按钮继续保留该角色的位置。右键“导”字停止导航；拖动按钮可调整位置，按角色保存。

窗口顶部按用途分为三个页面：**找 NPC、我的地点、当前导航**。找 NPC 时显示内置精选与已就绪的 Questie 扩展目录，个人收藏与自定义地点集中在“我的地点”，坐标表单和筛选条件按需展开。

目录和方向框均可拖动。Esc 关闭目录；搜索框内 Esc 先取消输入焦点。若窗口位置异常，输入 `/mynav reset`。

## 找 NPC

进入角色后，插件等待 Questie 完成语言与数据修正，再分批读取可定位 NPC。主目录标题会显示 Questie 读取、等待、失败或已接入状态；未装、未启用或尚未就绪时，原有 427 个精选点位仍可使用。扩展数量随已安装的数据库、可识别地图及可见相位变化，不代表所有 NPC 都有可靠位置。


1. 先选“全部 NPC”或用途分类：“职业训练师”“专业训练师”“声望与军需官”“材料商人”“特殊 NPC”“常用服务”“任务与其他 NPC”。“职业训练师”在下面按战士、圣骑士、猎人、盗贼、牧师、萨满祭司、法师、术士、德鲁伊九种角色职业细分；默认可查看全部职业，不会自动限制为玩家自身职业。现有声望分为 14 个声望阵营，材料按 8 种专业／用途分组，特殊 NPC 分为坐骑、武器训练、专业进阶和其他任务；常用服务增加其他商人、旅店老板、银行职员、拍卖师、兽栏管理员、修理和其他训练师；“任务与其他 NPC”可细分任务接洽、怪物与敌对 NPC、其他 NPC。分类依据已知用途、明确头衔和数据库功能标记，不推测商品库存。
2. 细分类有独立的“上页／下页”按钮，NPC 结果列表也可翻页。切换分类会保留搜索词；清空搜索或切回“全部”可扩大范围。分类旁数量是全目录记录数，不是经过阵营、区域与搜索筛选后的结果数。兼具制皮、裁缝用途的商人会同时出现在对应分组中。
3. 输入 NPC 名称、英文别名（数据库提供时）、副标题、声望名称、用途或 NPC ID。多个词以空格分隔，结果需同时匹配。此页不混入自己保存的地点；已收藏的 NPC 仍可在目录里查到，并显示收藏标记。
4. “筛选”默认收起。展开后可切换阵营与区域；默认显示本阵营、中立及双方敌对的怪物、整个世界；要找另一阵营的服务 NPC，可切换“阵营：全部”。结果默认“最近优先”，按可比较的直线距离排序并显示米／公里，也可切换“名称排序”。距离不可用或跨大陆时会明确标注。中立不代表初始友好，部分 NPC 需要声望或任务前置。
5. 选择结果后，右侧先显示姓名、用途、区域与坐标。地图 ID、NPC ID 和补充说明集中在默认收起的“更多资料”里，需要时再展开。
6. 点击“开始导航”，客户端支持时直接设置并启用原生航点追踪，无需先打开地图；点击“地图”则查看目的地区域。不支持原生追踪、处于战斗或副本等情形时按提示使用独立指引，副本内暂停方向。

职业训练师目录用于查找角色职业技能训练 NPC。“潜行者训练师”归入“盗贼”；普通专业训练师单列于“专业训练师”，宠物等其他训练师仍在常用服务中，不混入角色职业分类。目录记录参考位置，不会读取并推荐具体可学技能；等级、费用、阵营与任务条件请在游戏内确认。

同一个 NPC 在不同地图有记录时，保留各地图的目的地；同地图多个刷新点会从当前可见记录中选择参考点，当前地图优先选择较近点。开始导航后固定选中的位置，不随人物移动跳到另一个刷新点。目标相位不可见时暂停该目标指引，只释放仍属于本插件的原生追踪；相位恢复后不会自动抢回玩家或其他插件后来更换的追踪。收藏使用稳定的 NPC／地图标识，重载后等待数据库就绪再恢复。

## 找普通专业训练师

在“找 NPC”左侧选择“专业训练师”，再选采矿、草药学、剥皮、炼金、锻造、制皮、裁缝、工程学、附魔、急救、烹饪、钓鱼中的一项；其他已识别专业可看“其他专业”。细分类按每页 6 项翻页，选中 NPC 后使用同一套“开始导航”“地图”和收藏操作。主用途侧栏已为八项用途调整间距，方向浮窗保持原来的固定小尺寸。

可直接搜索“采矿训练师”“工程训练师”“炼金术”等关键词，也可输入 NPC 名称、副标题或 ID。数据库里的实际头衔可能是“初级炼金师”“高级铁匠”“大师级技师”，或者未翻译的 Junior 标题；这些训练 NPC 按对应专业归组。识别要求数据库同时给出训练功能标记和明确头衔，不因商人出售材料、技能书或头衔带“渔夫”就把它当作普通训练师。

已有部分进阶或专精 NPC 同时出现在“特殊 NPC”和对应专业中，保留原有标识与收藏，不重复新增同 NPC／地图点位。训练师名单不是可学技能推荐：等级、费用、阵营、已学技能与专精限制需在游戏中核对，插件不会替玩家学习专业或技能。本版新入口的实际显示、物理点击、训练师站位及可教内容尚未游戏实测。

## 从任务列表导航

打开大地图，在右侧任务列表中先选中任务，再点击任务详情底栏、原生“追踪”旁的文字“导航”按钮。底栏四个按钮同排，原生“追踪”保留原有逻辑。“导航”沿用下述任务解析，可查询 NPC、物品来源、要求前往的地点，以及完成后的交付地点；有多个目标时仍打开选择弹窗。新按钮的实际显示与鼠标点击尚待游戏验证。

本版接入右侧原生任务追踪列表与任务日志的任务条目：不按修饰键，用鼠标左键双击同一任务，可查询任务目标。也可先在原生任务日志中选中任务，再输入 `/mynav quest`，或输入 `/mynav quest 任务ID`。任务日志中的普通左键单击会稍等片刻以区分双击，再执行原生行为；Shift 点击与右键即时沿用原生行为。战斗中不延迟原生日志操作，双击任务导航请在脱战后使用。两个界面的物理双击及真实任务流程尚未游戏实测；若双击未触发，可使用命令入口。

客户端提供的任务下一站优先列出；缺少原生位置时，使用离线经典参考查找任务 NPC、物品来源、任务物件和任务地点。客户端任务航点可能表示任务区域或途中入口，不代表某个 NPC、物品的实时位置。物品来源可能是掉落 NPC、容器或商人，不保证必定掉落、当前有货或已满足领取条件。

- 只有一个可靠目标且当前进度明确时直接开始导航；多个候选或进度无法明确对应时，打开“任务导航 · 任务名”弹窗，由玩家选择。
- 弹窗每页显示 6 个候选，可用“上一页／下一页”翻页。每行显示类型、区域坐标与进度提示；选择时会重新核对任务状态，目标已变化则提示重新选择。
- 任务完成后，再点“导航”、双击任务或执行命令，查询交付 NPC／地点。已选目标完成或阶段变化时停止旧指引，再次双击选择下一目标；不会自动替换成另一个离线目的地。客户端任务下一站变化时只更新其方向参考，不重新抢占追踪。任务被放弃、交付后离开日志时，也会停止该任务的活动导航。
- 没有可靠坐标时显示缺失说明，可点击“原生任务地图”查看任务地图与文字；不会用玩家位置或地图中心代替。进度无法匹配时请核对任务文字，不按离线目标的排列顺序推断完成情况。

任务导航只保留一个临时活动目标，不写入“我的地点”或收藏，不占用 500 个自定义地点名额；停止导航、换目标或重载后清理。普通收藏、自定义地点继续保留。客户端任务级航点支持时使用原生任务追踪；明确选中的 NPC、物品来源或地点使用该点的原生用户航点，接口受限时按状态提示使用独立指引。停止只取消仍属于本插件的追踪，不删除共享地图标记，也不撤销玩家后来切换的其他任务追踪。

## 我的地点

“收藏地点”集中显示收藏过的 NPC 与个人地点，“自定义地点”显示自己保存的坐标。这里有独立搜索和排序，不会改变“找 NPC”页的搜索条件。收藏可在目的地详情中添加或取消。

“新增地点”默认收起，且只出现在此页。展开后填写地图 ID、X、Y 和名称，点击“保存地点”；保存成功后表单收起并选中刚保存的自定义地点。坐标填写 0–100，例如 X=55.9，而不是 0.559。“地图 ID”是游戏 UiMapID；表单初始会填入角色所在地图的 ID。

“保存当前位置”和“导入地图标记”也集中在此页。保存当前位置记录玩家站立位置；若新增表单展开，可使用其中填写的名称，否则采用当前目标名、子区域名或默认名称。以 NPC 为名保存仍不代表 NPC 的精确站位。

已有游戏原生地图标记时，点击“导入地图标记”，或输入 `/mynav pin`，将该标记保存为自定义地点并开始导航。相同坐标的已有自定义地点会复用；没有有效标记时显示提示，不改变当前目的地。这个入口读取原生用户标记，其他插件单独绘制的图标不一定能导入。

快速输入坐标可用 `/mynav way X Y 名称`，默认使用玩家当前地图；指定地图需在地图 ID 前加 `#`。支持用逗号分隔 X、Y，也支持将复制来的 `/way` 内容放在 `/mynav` 后执行。插件不注册或抢占全局 `/way` 命令；地图名形式的其他插件命令不能直接当作地图 ID 使用。

收藏和自定义地点按角色保存在 SavedVariables；最多保存 500 个自定义地点，可在详情里删除。发行安装包不包含任何角色配置或个人地点。

## 当前导航

此页专门显示正在导航的目标、区域坐标、直线距离、当前状态与原生追踪情况，并随位置轻量刷新。可点击“继续指引”“地图”或“停止导航”；没有目的地时会引导回“找 NPC”。

关闭目录后，独立方向框使用固定小尺寸的半透明框体，只保留目的地名称、箭头／方向、距离，以及“地图”和关闭两个按钮。箭头下按角色当前朝向标注八种相对方向：“前、左前、左、左后、后、右后、右、右前”，不是地图上的东南西北。到达、跨区或无可靠方向时显示“已到达”“跨区”“暂无朝向”等短标签，不编造前后方向，也不展开框体。方向框不再显示坐标、长说明、操作提示或悬停说明；详细区域、坐标与追踪资料仍在主窗口的“当前导航”页查看。名称区域可拖动并保存位置。点击“地图”查看目的地，关闭方向框会停止导航。0.3.3 曾在游戏中观察到达状态下的紧凑外观；本版新增数据库目录的实际点击、站位、相位变化与导航行程仍待游戏验证。

查看地图会显示插件自己的目标标记并收起目录。停止导航不删除共享的原生地图标记；只有仍属于本插件的原生追踪会停止，玩家或其他插件后来更改的追踪保持原样。

常用命令：

```text
/mynav                    打开或收起目录
/mynav 木喉               打开“找 NPC”并搜索可用 NPC 目录
/mynav 采矿训练师         搜索可用的采矿训练师参考
/mynav quest              查询原生任务日志中选中的任务
/mynav quest 任务ID       查询指定的日志任务目标或交付地点
/mynav save 我的钓鱼点     保存当前位置
/mynav pin                导入当前原生地图标记并导航
/mynav way 55.9 85.6 地点  导航到当前地图坐标
/mynav way 55.9, 85.6 地点
/mynav way #1453 55.9 85.6 自定义目的地
/mynav /way #1453 55.9 85.6 自定义目的地
/mynav go 1453 55.9 85.6 自定义目的地
/mynav stop               停止导航
/mynav reset              重置目录与方向框位置
/mynav help               显示命令帮助
```

## 覆盖与边界

内置 NPC 目录保持 427 个点位，覆盖东部王国、卡利姆多共 45 张区域及主城地图：职业训练师 195、声望与军需官 40、材料商人 109、特殊 NPC 26、飞行管理员 57。九职业训练师为战士 32、圣骑士 11、猎人 29、盗贼 24、牧师 28、萨满祭司 11、法师 24、术士 21、德鲁伊 15，分布在六座主城及部分新手、野外区域，共 19 张地图。以上是无需 Questie 即可使用的精选底库。启用 Questie 扩展后，可定位记录加入同一目录，并按 NPC ID／地图去重保留原有精选标识。客户端不认识的地图、副本地图、无效坐标以及当前不可见的相位不会被伪造成可用目的地；缺少记录时仍可保存自定义地点。

任务离线参考单独维护，涉及 3,817 个至少具有一处可定位目标或交付参考的经典任务：其中 3,762 个有交付参考，1,365 个至少有一项 NPC、物品来源、物件或区域目标可定位，覆盖 46 张地图。这不表示每个任务的全部目标均可定位，也不代表可自动完成 3,817 个任务；任务参考与 NPC 搜索目录分别维护；本版扩大 NPC 搜索范围，不代表离线任务参考也完整覆盖所有新增任务。任务坐标、关联和地图经过公开资料交叉核对，实际站位、进度识别、可达性及真实任务流程仍需游戏内核验。

导航支持客户端可识别地图上的自定义坐标。方向和距离是直线参考，不计算山路、洞穴入口、建筑楼层、水域绕路或最短步行路线。跨大陆时方向框只显示短状态标签，交通参考可在“当前导航”页查看；抵达目标大陆后自动恢复方向。不会代替玩家移动、选择航线或点击 NPC。

距离显示为米或公里；每次开始导航后，首次进入目标坐标约 27 米范围时显示一次到达文字，方向框显示“已到达”短标签。默认不播放声音、不自动删除标记，也不会切换到下一地点。到达判断不代表已经找到 NPC 或可以交互。副本内暂停方向指引；坐标、朝向或地图尺寸不可用时，方向框只显示短状态标签，详细说明在“当前导航”页查看，不编造箭头或距离。

本版没有道路 ETA 或自动路线队列。距离排序和原生追踪都不能判断山路、建筑楼层或实际通行条件。

内置精选点和离线任务参考来自固定版本的 pfQuest MIT 数据，保留原来源与声明。扩展目录只读本机已安装 QuestieDB 的公开 API，使用其当前语言、Forever 修正、功能标记和参考刷新位置；不改变 Questie 设置，不将其数据库、运行代码或品牌素材随包分发。参考位置不等于 NPC 实时位置，覆盖量取决于用户的数据库版本和客户端地图。来源和许可分别见随包 `SOURCES.md`，不能将 QuestieDB 整库视为 MIT 数据。
