# 我的无限 · 目标选择 0.1.45 本机原生命中探针候选

本轮追查了11套插件/分支的实际战斗焦点代码，仍未找到任意同名NPC按GUID自动确认的可移植实现。0.1.45没有加入人工焦点流程，也没有放开原有脱战兼容的战斗守卫。

新增默认关闭的`/mytargets platescale 1`原生几何/鼠标诊断，将1替换为未选中活怪所在的敌方格号。仅脱战、原生姓名板所有者及公开身份可核验时准备；最长15秒，前10秒缩放并映射到临时非交互框，随后恢复本次原值，在同一框继续5秒只读对照。请静止面对站立怪物，把鼠标停在框内同一点，不点击、不施法；结束后`/reload`保存。准备失败会显示原因并记录；`platescale stop`请求提前恢复，`status`查看状态。

探针不执行目标/焦点/技能/绑定动作，不改全局姓名板尺寸或CVar；只有显式启动才创建观察器与被动写入跟踪。中断请求恢复，战斗中延期到脱战，其他插件较新写入不覆盖。两阶段同时恢复缩放和映射，日志只保存组合观察、scaleEffectProven恒为false，不把GUID匹配或模拟当成战斗修复。24个Lua语法、10284项模拟及独立复核通过，原生C++命中与恢复仍待游戏验证。本机候选未发布。

以下保留0.1.44布局和0.1.43焦点路径的历史验证范围。

友方面板默认改为屏幕左侧、垂直中线偏上，给左侧“目”字图标及底部动作条留出空间；格子尺寸不变。仅未手动摆放且仍为旧默认的坐标自动迁移；已有手动位置继续保留。敌方面板与图标的默认位置不变。

诊断日志开启时自动记录实际视口、缩放、两侧面板和已知原生动作条的矩形位置，每秒观察、几何变化才保存。重叠结果区分相交、不相交和不可确认；这是几何证据，不代表自动检查了游戏画面，也不覆盖任意第三方动作条。停止和重载前补最后位置，沿用最多4小时、5000条记录。23个Lua语法、9820项模拟及独立复核通过。2026-11-12实际1920×1080、两侧5格场景中，初始及拖动后的面板均未与可见原生动作条相交，用户确认友方面板正常，最终位置已保存；其他比例、容量及下一次加载尚未逐项实测。本机候选未上线。

以下保留0.1.43焦点优化及此前版本的实际验证范围；各版本与操作路径分别记录，不扩大上述布局验收范围。

0.1.43默认合并“确认焦点”和第一步恢复：找到指定GUID后再右键一次，先设焦点，再清空原空目标、返回已核验的独立单位，或执行一次反向选敌。两步的实际结果分别核对，未回到原GUID时继续显示“尚未完成”，后续右键只做恢复，不重复给别的目标设置焦点。通常可以少一次右键；多个敌人不在同一宏里循环。

如果恢复命令没有执行且目标未动，会在本次会话退回分步恢复。也可在没有进行中的流程时用`/mytargets focuscycle staged`手动切回已验证的分步模式，`combined`重新启用合并；模式仅本次会话生效。进度文字突出下一步及“完成”条件，保持现有格子与面板尺寸；减少独立单位表构造及重复注册可见状态驱动。

0.1.42已有空/非空原目标恢复的实际阳性。2026-11-12实际日志确认0.1.43合并动作5次完整成功：两次右键准确设B焦点并恢复A，延迟读回一致；另1次恢复未完成后中止保留。此次原目标均非空，空原目标及完整多步恢复仍待0.1.43游戏验收。完整语法、模拟与独立审查已通过；本机候选未上线。

0.1.42加入用户同意的同名怪多次右键流程，仅脱战：右键需要的怪物格子启动，每次右键只选下一只，始终按启动时冻结的GUID核对；找到后再右键确认焦点，随后按提示继续右键恢复原目标。处理中固定敌方名单，格子上显示进度；中央临时按钮也可继续操作，左键取消寻找并准备恢复。旧焦点在命中前保留。原目标为空时恢复为空，原目标是可验证的队员等独立单位时直接返回，其余可循环敌人逐次反向选择、只按原GUID确认恢复；不使用多次切换后的targetlasttarget冒充原目标。

只有实际焦点GUID等于所点怪物、当前目标确实回到原目标时才显示完成。找不到或无法恢复会保留未完成提示，玩家可手动选回原目标；`/mytargets focuscycle restore`准备重试恢复，`/mytargets focuscycle stop`直接停止并保留当前目标。开始前若原目标无可用恢复方式，会拒绝启动并提示先清空目标。进入战斗或光标携带待施法/物品时暂停，手动更换目标或焦点会停止流程。重载不续接未完成事务。此流程会改变上一目标历史。

两次独立点击切到两只同名狼已在0.1.41实测。0.1.42又完成4次同名强盗的准确焦点与空原目标恢复实测，以及3次非空原目标恢复阳性；先前11次中止记录保留，不算作成功。友方别名、名字恢复及战斗中断等边界尚未全部游戏验收。公开版本仍0.1.37。实际操作与验证范围见PersonalAddons中的GUID-FOCUS-FLOW.md和TARGETS-VALIDATION.md。

0.1.40加入默认关闭的Tab循环入口探针：`/mytargets focusprobe cycle 1`一次右键测试同一安全宏两次选敌；`cyclecontrol 1`分两次右键作对照。只有脱战、空原目标、无待施法或物品光标时开始，选择过程中被动记录GUID；对照第二步只接受第一步记录的目标。结束清空测试目标，焦点全程不改。成功准备时自动开始新日志时段，测完`/reload`保存。尚未游戏实测，不能据此认为同名怪焦点已修复；正式格子的点击逻辑未改，公开版本仍0.1.37。

0.1.39增加默认关闭的焦点接口探针，正式格子的右键处理保持0.1.38。2026-11-11本机脱战实测：姓名板单位原生focus、原始GUID按钮、无unit属性的GUID焦点宏均未设置到预期怪物；同一测试按钮改用player单位后成功设置本人焦点。GUID能用于区分和核验身份，但上述直接焦点路线没有奏效，尚未实现同名怪直接右键格子设焦点。测试按钮和临时按键已清理，未发布。

适配国服《魔兽世界：无限》1.60.1（build 70862，Interface 16001）。下载及更新说明：https://afabiaoge.xyz/targets/ 。完整退出游戏后，将整个 `MyForeverTargets` 文件夹放入 `_forever_/Interface/AddOns/`；保留原有 WTF 和 SavedVariables，再启动游戏。包内已包含所需距离库，无须单独安装。

两侧标题栏右端各有“×”，只关闭对应面板，关闭状态在重载后保留。屏幕左侧中间有与聊天、商业技能助手和世界向导同款的玉绿色“目”字图标：左键打开菜单，分别开关友方、敌方面板或全部打开／关闭；右键快速显示／隐藏两边。两边关闭后图标仍在，拖动图标可保存新位置。战斗中的面板开关会在脱战后应用；菜单显示待开／待关状态。`/mytargets reset` 可恢复面板与图标位置并打开两边。

提供脱战普通技能悬停兼容方式：鼠标悬停后按原技能键，内部临时选中该单位、施法，再恢复施法前的目标；原来没有目标则恢复为空。会改变lasttarget历史。这不是让游戏原生mouseover自动识别所有附近单位。

两侧“施法”按钮控制同一个开关，也可用 `/mytargets legacycast on` 或 `off`。只接入普通技能：友方使用治疗／增益，敌方使用伤害。已有宏、物品、绑定在鼠标按键上的技能和其他插件占用的键不接入施法桥；不创建或改写玩家宏，不保存新的永久键位。目标本来已被选中时直接施法，无需重新选中。

此恢复版仅支持脱战。移开、隐藏、死亡、单位身份失效或进入战斗会交还原键；战斗中不临时创建新的目标动作。名称方式无法按GUID区分同名怪物，已发现同名或无法确认唯一时不准备名称选择施法。施法仍受技能等级、距离、视线、朝向和游戏规则限制。

界面保持：友方团队20、小队5、附近5/10/20；敌方单列表5/10/20。附近按距离排序，悬停时暂缓所在名单重排。76×58主格显示姓名职业色、整格血量、底部资源条；友方不重复写职业。敌人下方独立76×26目标条显示姓名、职业、血量，完整名字见浮层。当前目标用红框，当前焦点用黄框；同一单位同时是目标和焦点时两种框均保留。友方、敌方及敌人的目标条统一为左键选中、右键设为焦点、Ctrl+右键打开标记菜单。再次点击同一格不取消目标或焦点。

主格保持76×58，格子横纵间距及敌人到下方目标条的间距均为1像素。上排只显示自己（含本人宠物、载具）施加的有时限增益，虔诚光环等常驻增益与采集追踪不显示；下排显示自己施加的减益，友方还包括本人可驱散的减益，并以黄色角点提示。两类友方减益互斥，不重复显示。每排6枚10像素图标，更多效果用滚轮查看，不悬停展开。图标保留消退动画，不叠加层数文字。敌人的目标改为76×26小条，仅显示姓名、职业、血量，不创建buff/debuff图标，也不接管滚轮。

脱战拖动标题栏后立即保存手动位置，普通刷新、切换容量和重载不会因两面板重叠或靠近动作条而把它搬回左上；屏幕实际边界仍限制越界。尚未手动摆放时保留自动适配。战斗中暂停拖动；若拖动中进入战斗，取消本次拖动并保留原位置。战斗中若无法读取光环滚动范围，沿用最近确认的范围；新出现的超视口效果可能暂时无法滚到，脱战后刷新范围。

当前目标不显示额外头顶标记。焦点保留金色动态菱形和“焦点”文字，与原鼠标悬停动画错开放置。标记只跟随游戏实际可见的姓名板；无姓名板、离开视野或身份不可读时隐藏，不修改姓名板的位置或鼠标命中区域。

附近姓名板单位的右键焦点采用脱战兼容方式：短暂选中完整名称、设为焦点，再恢复原目标；已是当前目标或焦点时避免额外切换。自己、小队和团队保留原生焦点动作。焦点操作独立于“施法”开关，名称方式的同名限制仍适用，战斗中不准备名称兼容动作。

日志通过 `/mytargets log start` 开启。新桥日志记录原按键、预期单位、选择前后目标、施法事件；焦点日志另记操作前后焦点、原目标恢复和拒绝原因。按键已派发或配置已准备不等于成功。测试结束 `/mytargets log stop`，再 `/reload` 保存。

这是试用版本。附近友方的脱战普通治疗／增益和原目标恢复已有用户实测；敌方和敌人的目标条施法尚未验证成功，原生敌方方块 `@mouseover` 仍有已知限制，不应依赖其完成战斗施法。具体验证范围见包内 `VALIDATION.md`，第三方库来源与许可见 `Libs/SOURCES.md`。公开管理器0.2.1支持目标插件的下载与更新，旧管理器需要先从官网替换新版程序。
