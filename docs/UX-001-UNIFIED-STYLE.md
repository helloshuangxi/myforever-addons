# UX-001 第一阶段：统一样式与信息层级

日期：2026-11-14。分支 `feature/ux-001-unified-style`。范围是七个自研插件的游戏内界面代码。

**状态：候选，未经游戏实看，未发布。** 以下画面全部来自离线布局模拟（`tools/ui_preview`），不是游戏截图。UX-001 仍为 open，需要在客户端实看后由用户确认。没有修改任何版本号、发行包、官网或部署；商业技能助手 `0.4.7-dev.22` 的发布限制原样保留。

## 改前查到的事实

| 现象 | 依据 |
| --- | --- |
| 七个插件各有一套配色和控件 | 宏工坊用暴雪原生石框与红色按钮；行为采集蓝黑底加提示框边；随身手册青色边；商业技能助手金色边；世界向导与目标选择各自的扁平线框；聊天是独立的翡翠色 |
| 标题、聊天前缀写法不一 | “我的无限 · X”“MyForever · X”“X”三种并存，前缀颜色四种 |
| 主次不分 | 行为采集六个等权按钮、全部金色文字；宏工坊十二个模板与三个操作按钮外观相同 |
| 功能状态只在聊天栏或长提示里 | 采集提醒是否可用只打印到聊天栏；悬停施法是否就绪只写在悬停提示的长句里 |
| “静石”设计提案从未进入代码 | `design/modern-flat-20261111/tokens.json` 标注 `design-proposal-not-implemented` |

## 做了什么

### 1. 共用样式模块 `MyForeverStyle.lua`

源文件 `PersonalAddons/shared/MyForeverStyle.lua`，每个插件内嵌一份相同副本并排在 TOC 第一行（各插件仍可单独发行）。`python3 tools/sync_style.py` 写入副本，`tools/check_addons.py` 会检查七份副本一致。

- **配色**取自已发布聊天插件的默认“翡翠”外观（石墨底 + `#6BD194` 绿），与官网和三个收起图标一致。因此聊天插件本身未改界面代码。
- **文字层级**：title / heading / body / secondary / caption / value 六级，对应主内容、标签、说明和关键数字。
- **按钮分级**：primary（每个视图一个主操作）、default、quiet（偶尔用的文字操作）、selected（当前选中）。
- **底板不透明度**按角色：窗口 0.94、HUD 0.72、提醒 0.82；只改底板，不对父框体 SetAlpha。
- 游戏语义色不进样式模块：目标红框、焦点金框、职业色、物品品质色、配方难度色、聊天频道色全部保留在原处。
- 所有控件调用都带存在性检查，样式函数不会因为客户端差异抛错。

### 3. 让“不能用”看得见

两项功能受客户端限制（见下节）。之前它们失败时界面没有任何表示，玩家只会觉得插件坏了。

- **商业技能助手**：标题栏“采集”按钮按真实状态着色——绿色为提醒已开启，琥珀色并显示“采集 !”为客户端限制读名或未开启小地图追踪，灰色为已关闭；悬停提示第一行写明当前状态。只读取采集模块已公开的标志，不改扫描逻辑。
- **目标选择**：每个格子右下角一个小点——绿色表示此单位现在可以悬停后按普通技能键施法，琥珀色表示同名单位无法确认唯一、未准备；战斗中、已关闭或尚在检查时不显示。它是普通贴图，战斗中显隐不涉及受保护属性。

## 没有解决、也不能在这里解决的两项

这两项我读了代码和全部调查记录，结论是卡在客户端，不是界面或代码缺陷。没有游戏客户端，以下均未实测。

**敌方面板不能悬停施法（MFT-001 / MFT-002）。** 已有实机记录显示：格子的 unit 属性正确解析为 `nameplate1` 且 GUID 一致，但客户端的真实 mouseover 仍是别的单位；原生 `TargetUnit(nameplate1)` 已派发而目标未变。也就是这个客户端不让插件框体把姓名板单位变成鼠标单位。现有的脱战“按名字临时选中—施法—恢复”只对名字唯一的怪有效，并且用 `stopmacro[combat]` 主动在战斗中停用。

一个值得实测的方向（未实现）：`/targetexact` 本身在战斗中可用，受限的是战斗中不能改按钮属性。可以在脱战时为当前已知的、名字唯一的敌人预先写好名称宏，战斗中沿用；战斗中新出现的怪和同名怪仍然覆盖不到，目标恢复也需要重新验证。是否值得做取决于实际打怪时“名字唯一”的比例，需要作者在客户端判断。

**自动小地图找矿不工作（MFP-001）。** dev.22 的记录是小地图提示文本被客户端标记为受保护值，10 次读取没有一次得到可用名称。在找到当前版本里公开且新鲜的名称来源之前，任何扫描方式都拿不到矿名；继续换搬图方式不会改变这一点。近处资源的提醒、声音和闪光走的是另一条路径，不受影响。

**更新：** 后来换了思路——不读矿名，只把受保护的名称交给游戏显示。已实现为候选，见 [加密矿名直显](MFP-001-SECRET-NAME-PASSTHROUGH.md)，未实测。

1. 七个插件各打开一次：字号是否合适、底板透明度在亮/暗场景下是否可读、1px 边线在当前 UI 缩放下是否清晰。

3. 商业技能助手：窗口拉伸、技能书、收起图标是否与之前一致；“采集”按钮三种状态。
4. 目标选择：战斗内外格子就绪点的显隐；确认没有 `ADDON_ACTION_BLOCKED`。
5. 世界向导 HUD 透明度是否仍是之前认可的样子。

## 后续

- **第二阶段（布局）**：世界向导 900×600 与聊天 840×560 仍是最大的两个窗口；世界向导右侧详情栏大半空白，可以收窄。这需要重排坐标和大量既有断言，应在第一阶段实看通过后再做。
