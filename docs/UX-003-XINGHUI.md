# UX-003 星辉：我的无限自己的界面风格

日期：2026-11-14。分支 `feature/ux-001-unified-style`。不改版本号，不发布。

作者想学日式主机游戏的界面风格。我先给了三个方向（`docs/ux-001/` 里的设计稿：怪盗风、水晶、任天堂），作者的回复是：再查其他 3A 大作，或者融合出一个自己的风格。最后定为“星辉”。

## 原则：哪里用什么

- **菜单窗口**（世界向导、商业技能、宏工坊、玩家行为）：玩家在这里停留得久，可以有表现力。
- **战斗面板**（目标选择）和 HUD 类面板（随身手册、导航指引）：保持克制，不加装饰。
- **战斗中**：一律不播动画、不出音效。

## 借鉴来源

| 元素 | 借鉴 | 依据 |
| --- | --- | --- |
| 深蓝半透明底 | 保留现有的“午夜”配色 | 原神、最终幻想的半透明分层 |
| 金色四角包角、标题加宽字距、标题下渐隐金线 | 最终幻想 XIV / XVI | 奇幻典雅，和魔兽气质最接近；包角只用在窗口级别 |
| 选中项：斜切光带 + 呼吸的金色菱形光标 | 女神异闻录 5、暗喻幻想；命运 2 的光标 | 选中项要一眼看出来。Atlus 承认初版菜单“读不了”，所以不用倾斜文字，只用光带 |
| 窗口下方的按键提示条 | 任天堂 Switch、塞尔达 | 主机游戏常见的操作提示 |
| 打开、关闭、点击的短音效 | 日式 RPG 通用 | 只用游戏自带音效，可一键关闭 |
| 打开时 0.15 秒淡入上滑 | 命运 2、原神 | 轻量过渡 |
| 战斗面板不加装饰 | 对马岛之魂、艾尔登法环 | 轻 HUD：只在需要时出现 |

**刻意不学的：**
- 倾斜文字和满屏动画：难以阅读，魔兽也做不到倾斜文字。
- 暗黑破坏神式石材、金属贴图：插件里贴图越多越显旧。
- 艾尔登法环式“信息靠猜”：插件本来就是为了降低门槛。

## 实现（共享样式 v5）

### 新增接口

- `S.Corners(frame)`：窗口外角各一个 12 像素的 L 形金色包角。
- `S.WindowTitle(fs, text)`：
  - 6 个字以内的纯中文标题加空格模拟字距（字体对象不支持字距）；
  - 标题用暖白色；
  - 尝试 `Fonts\ARKai_T.ttf` 字体，`SetFont` 返回失败就退回原字体。
  - 注意：简体中文客户端的默认字体本身就是它，所以字体不会有区别。
- `S.TitleRule(parent, left, bottom, width, top)`：从金色渐隐到透明的 1 像素横线。
- `S.MarkSelected(row, on)`：
  - 蓝色斜光带，宽度为行宽的 70%，向右渐隐；
  - 6 像素的金色菱形（白色方块旋转 45 度）；
  - 菱形 0.9 秒往返呼吸，战斗中停止。
- `S.Sound(kind)`：
  - 用游戏自带的 SOUNDKIT 音效：打开、关闭、选择、确认；
  - 走 SFX 声道；
  - 战斗中不响，登录后前 4 秒不响；
  - `/myui sound`（或 `/myui 音效`）切换开关，保存在各插件共用的 `MyForeverStyleDB`（账号级）。七个 TOC 都加了这个 SavedVariables 声明。
- `S.WindowMotion(frame)`：显示时 0.15 秒淡入并上移 6 单位，同时播放开、关音效。受保护的框体和战斗中跳过。
- `S.HintBar(frame, items, trailing)`：窗口外下方的键帽提示条，不挤占原有布局。

### 自动生效的地方

- `S.Panel(frame, "window" | "popup")` 自动加包角和动效；`hud` 不加。
- `S.TitleBar` 自动处理标题并加金线。
- `S.Button` 通过 PostClick 播放点击音效，所以调用方后来替换 OnClick 也不受影响。

### 各插件改动

- **世界向导**：
  - 标题和金线；
  - 提示条：左键 选择 · Esc 关闭；
  - 列表选中改用 `MarkSelected`，名字和说明右移 12 像素，给光标让位。
- **商业技能**：标题和金线；提示条：Esc 关闭。
- **宏工坊**：提示条：Esc 关闭。
- **玩家行为**：提示条：拖标题栏 移动。这个面板不响应 Esc，所以不写 Esc。
- **目标选择、随身手册**：不变（克制）。

## 验证

- 新增 `style_xinghui_test.lua`，共 32 项检查，覆盖：
  - 标题字距与字体回退；
  - 包角数量且不重复添加；HUD 面板不加装饰；
  - 音效：登录静默期、战斗静默、按钮确认和选择、开关；缺少 SOUNDKIT 时不报错；
  - 选中光标的显示、隐藏和呼吸，战斗中停止呼吸；
  - 提示条；标题栏。
- 全部 72 个测试通过。
- 预览图 `docs/ux-001/xinghui-windows.png`：离线模拟渲染，不是游戏截图。
  - 预览工具新增了渐变绘制，模拟环境补了 `CreateColor`。

## 需要实机确认

- 包角和提示条画在窗口外侧，窗口贴近屏幕边缘时会被裁掉。
- 音效的音量、选的具体音效是否合适。
- 菱形旋转贴图在不同界面缩放下是否清晰。
- 多个插件声明同一个账号级 SavedVariables 的实际保存行为。
